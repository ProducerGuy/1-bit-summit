### 0A. Prior commitment and clarification

Before opening sources I stated these subjective probabilities: **P(90% retention) = 45%; P(99% retention) = 8%.** They remain the prior entries in section 4. The event is existence of a repeatable successful training procedure at the specified shape and codec, not success of any individual run. No training or reading budget is used as a reason to discount either event.

Three ambiguities in the assignment must be fixed before discussing methods:

1. A model's latent weight, effective forward weight, and serialized weight are different objects. The first can move while the second and third remain unchanged. A full-precision training path has no stored binary model except at an explicit projection checkpoint.
2. The phrase 'until weights sit on the cap' is not a consequence of clipping. It is a new constraint. A fixed norm can make that constraint exact, but must be feasible, and at the exact endpoint signs become disconnected.
3. The project specifies tied embedding and output scales. It cannot use a separately learned input and output scale table even with shared signs. Also distinguish the matrix codec 1.125 bpw from actual model bits including normalization gains, metadata and padding. If normalization gains are required to be binary too, that is a different target from the released reference; the project owner should explicitly pin the accepted tensor manifest. ## 1. Training on a two-value lattice

### 1A. Notation, projection and the only honest definition of step zero

The following is original analysis from the stipulated format, not a literature result.

Let n=128. A group is a vector w in R^n. The feasible dense set before scale serialization is C = {a s : a >= 0, s in {-1,+1}^n}. The deployed set C16 additionally restricts a to finite, nonnegative FP16 values. Define sign(0)=+1 for deterministic export. A negative stored scale can be canonicalized by negating every sign in that group and making the scale positive. This is gauge fixing, not a change in effective weights. Zero scale is degenerate: all sign vectors represent the same zero group.

For a fixed sign vector s:

    ||w - a s||² = w^T w - 2 a s^T w + n a².
    derivative with respect to a = -2 s^T w + 2 n a.
    a*(s) = max(0, s^T w/n).

The maximizing sign choice is s_i=sign(w_i), with s^T w = sum |w_i|. Hence the Euclidean projection Q(w) has a = mean |w_i| and

    ||w-Q(w)||² = sum w_i² - (sum |w_i|)²/n
                 = n Var(|w|).

The last equality follows by expanding sum (|w_i|-mean|w|)². This is an exact identity. If the scale is rounded to finite FP16 value a16, the added squared error is n(a16-a*)², because the first derivative at a* is zero. This separates sign/magnitude fitting error from scale representation error. If a* is not representable, no implementation may claim an exact initial conversion from a FP teacher. If the teacher group happens already to have equal representable magnitudes, the error is zero.

For an activation-aware projection use H positive semidefinite, for example H=E[x x^T] in a linear layer or a chosen regularized Hessian surrogate. Let J=.5(w-a s)^T H(w-a s). Then

    J = .5 w^T H w - a s^T H w + .5 a² s^T H s.
    a*(s) = max(0, (s^T H w)/(s^T H s)) when s^T H s > 0.

A zero denominator implies Hs=0 for PSD H. The objective is then invariant to a. Damping makes the denominator strictly positive. For H=I this reduces to the Euclidean rule; for general H the sign(w) vector need not be optimal. For H diagonal positive, sign(w) remains a minimizing sign choice, but scale is a weighted rather than arithmetic mean. For dense H, the signs interact. These are layer-reconstruction objectives, not guaranteed global task loss reductions. Every F-like initializer should be judged by both the local criterion and subsequent teacher KL and task score, not by W MSE alone.

Define two starts: R is the already packed, strict tied model with exact s0,a0 decoded; P is full-precision parent w0. Native Boole is not R unless it is first retied and its scale type converted as needed. A BF16 scale is not interchangeable bit-for-bit with FP16: BF16 has a wider exponent range and lower mantissa precision; outside FP16 finite range, exact conversion is impossible. Even within range, very tiny numbers need a representability check. Any lossy retie is an explicit pre-stage, never hidden in initialization.

Step zero requires the forward computation to equal the intended starting function, including norms, tied aliases, attention scaling, masks, and tokenization. Algebraic equality of one matrix is necessary, not sufficient for runtime parity. In the following derivations assume other tensors and computation fixed. Store a group exactly once. If the teacher is copied in full precision and the student forward is identical, pure deterministic KL distillation has a zero first gradient. For probabilities p=softmax(z_T), q=softmax(z_S), derivative of KL(p||q) with respect to student logits is q-p. At q=p this is zero. Consequently methods B/C which start exactly at P cannot start learning from pure teacher KL until some constraint, initialization perturbation or additional loss acts. A starts learning because its initial hard forward is already different. This is a distinction independent of optimizer speed.

### 1B. Candidate A: straight-through training

Specify a complete estimator rather than just saying STE. One legitimate version uses q=Q(z), forward packed scale a16=round16(mean|z|), and backward dq/dz approximated by I. This differs from differentiating the magnitude estimator exactly while applying STE only to sign. If sign derivative is approximated by 1, the latter Jacobian before rounding is a I + ss^T/n (depending on the chosen clipping mask). The first rule treats the entire quantizer as identity in the backward. The second has both a scale-dependent effective learning rate and a rank-one shared term. They are not the same algorithm and cannot be compared without saying which is used.

For R: initialize z=a0 s0. Mean magnitude equals a0, so forward q0=R exactly, barring floating reduction or sign convention bugs. This passes the initial function test. A second valid initialization is any z with the same sign and mean absolute value, but different margins. It is not necessary to set every latent equal to the stored weight. This is a new degree of freedom in the optimizer state, not deployed capacity.

For P: initialize z=w0. The initial effective forward is Q(w0) and differs from P by the error derived in 1A. Keeping w0 in the latent tensor does not mean starting at the teacher's performance. Quantize immediately and measure that baseline before training. For a model with tied embeddings, both lookup and classifier must reference this same q; reconstructing only one of the roles is invalid.

First-step analysis for SGD with whole-quantizer STE:

    z_i' = z_i - eta g_i, g = dL/dq.
    s_i changes iff z_i z_i' < 0, or a specified zero tie is reached.
    For R and nonzero a0: crossing requires eta s_i g_i >= a0.
    While signs unchanged, |z_i'| = |z_i| - eta s_i g_i.
    a' = a - eta (s^T g)/n.

Thus a sign does not flip merely because a gradient is nonzero. At ordinary rates the margin can be huge relative to the realized update. With a0=.02 and a realized normalized update of .00001, 2000 same-direction updates are needed to traverse the initial margin absent scale coupling or momentum. This is illustrative arithmetic, not a recommended model rate or a measured Qwen statistic. An adaptive optimizer changes the effective step, not the crossing condition. Log actual z deltas and crossing frequencies. Even if every sign is frozen at first, scale can move through mean magnitude. If the signed gradient sum cancels, it will not move to first order. If a' remains in the same FP16 rounding cell, the actual serialized model does not change either. Near .02, FP16 spacing is approximately 2^-16 = .00001526; the threshold to the next cell is roughly half a spacing for a0 exactly at its center. Keep full-precision scale or latent accumulators if trying to move across these cells. Never discard the accumulator each step by overwriting it with the cast scale.

There is no single guaranteed learning rate that both flips useful signs and avoids destructive global changes, because groups have different scale, curvature and accumulated gradients. A normalized margin m_i=|z_i|/a and update ratio |delta z_i|/a quantify the issue independent of layer magnitude. One can choose latents with low margins for some signs while preserving the mean: if k entries get magnitude epsilon and n-k entries get magnitude (n a-k epsilon)/(n-k), mean is unchanged. This cannot make all n margins simultaneously tiny while maintaining a unless a is also tiny. Extreme compensation margins can create other stale signs. Better separate sign latent z from learned scale a, use z0=s0 or epsilon*s0 and a0 exactly, and train a directly. This is a distinct A-prime variant, not the original mean-magnitude rule. It maintains the same deployment codec and decouples margin inertia from weight amplitude.

End point: the hard forward q already fits C if a positive, and C16 if the cast is used in every forward. No final sign-rounding gap. If the forward uses FP32 scale and the export uses FP16, scale rounding remains; measure it, or use QAT of the scale. A soft validation forward, latent-only inference or re-derived scale at export is not a valid endpoint. For the tied matrix, accumulate both gradient paths before changing z or a. A-prime's independent scale derivative is derived below; the mean-magnitude rule is not equivalent to that derivative.

Recommendation: retain A as control and A-prime as strong candidate. Do not force the shadow values of a warm start to have physical weight magnitude if the scale is separately trainable. Save optimizer state, latent margins and scale master values in the training checkpoint, not in the deployed artifact. Record actual packed changes per tensor each step. This is scientific instrumentation, not a modification of the deployment format.

### 1C. Candidate B: the shrinking cage

Write y=w-eta g(w). Standard clipping is w'=clip(y,-c,c), the projection onto box B(c). It never forces an interior coordinate toward a boundary unless the gradient, other constraints or the changing cap does so. If L(w)=||w||² and w=0, every iterate is zero for all positive c. At a positive cap this is not a binary group. If c tends to zero, the model becomes all zero, not useful binary. The problem statement needs a precise closure rule.

Let r be a target group L2 norm. Define S(c,r) = {w: ||w||2=r and |w_i|<=c}. Feasibility is equivalent to r<=sqrt(n)c, provided r>=0. Necessity follows by summing squares. Sufficiency follows by choosing all magnitudes r/sqrt(n). At c=r/sqrt(n),

    r²=sum w_i² <= n c²=r².

Equality means every squared magnitude is c², because a strict inequality in any term makes the sum smaller. Therefore the feasible set at closing cap is exactly {c s}. This is a genuine mathematical guarantee of the endpoint, not of a good solution or of convergence of gradient descent to it.

A projection cannot be implemented merely as `clip` then rescale to norm r. If the clipped vector has norm below r and any coordinate is at c, rescaling above 1 violates the cap. The reverse order also fails the norm. For nonzero generic y, solve the nearest-point problem:

    minimize ||w-y||² subject to w in S(c,r).
    Since ||w||²=r² fixed, maximize w^T y.
    sign(w_i)=sign(y_i) is optimal for each nonzero y_i.
    Let v_i=|w_i|. Maximize sum |y_i| v_i, with sum v_i²=r², 0<=v_i<=c.
    For unsaturated coordinates, |y_i|-2 lambda v_i=0.
    v_i=min(c,t |y_i|), t=1/(2 lambda).

Choose t by bisection of sum min(c,t |y_i|)²=r². This function is monotone increasing for t>=0; if enough nonzero y exist it spans the desired range. If some y_i=0 and the desired norm exceeds the maximum achievable using nonzero coordinates, saturate the nonzero entries and allocate remaining norm deterministically among zero coordinates. At closure all coordinates saturate, signs of zeros chosen by explicit tie rule. The Lagrange construction is globally optimal when it applies: the same v maximizes the separable concave function sum |y_i|v_i-lambda sum v_i² on the box, and all competing feasible v have the same squared norm. It is not proof of convergence of nonconvex projected SGD, especially with a changing c. It is a computable projection definition.

R start: r0=sqrt(n)a0. Starting cap c0=a0 already closes the cage. Any smaller cap is infeasible at fixed r0. If a useful continuous path is desired, start with c0>a0, keep w0 intact, then lower to a0; this is a widen-and-close schedule even though initial weights do not move. At a closed cage, the Euclidean projection is binary at every step and the same sign-crossing threshold returns. At an open cage the first exact gradient may change w even without changing its projected signs. The hard deployment projection may still not move. If the norm and cap remain fixed at closure, all scale degrees of freedom are frozen. The warm-start distillation gradient is generally nonzero unless student and teacher happen to produce identical predictions on the chosen text. No guarantee that opening the cage helps.

P start: select r0=||w0||, c0>=max |w0| and the forward exactly equals P. Under pure deterministic KL gradient the first step is zero as described in 1A. A lowered cap induces the first perturbation. At closure a_RMS=||w0||/sqrt(n), not the mean magnitude. Compare against Euclidean optimum a_mu=mean|w0|:

    ||w0-a_RMS sign(w0)||²
      = ||w0-a_mu sign(w0)||² + n(a_RMS-a_mu)².

RMS >= mean by Cauchy-Schwarz, equality only at equal magnitudes. Fixed norm imposes an avoidable reconstruction bias for heterogeneous groups. In an activation-aware metric the optimal norm may differ even more. A better formulation sets a separately learned positive scale and a scheduled shape parameter rho>=1:

    ||w||2=sqrt(n)a, |w_i|<=rho a, rho falls to 1.

This defines a normalized shape cage with free norm. At rho=1 every group is binary with scale a. At step zero set a=RMS(w) and rho at least max|w|/a. At closure use representable a16 and choose r consistent with it; do not insist on an incompatible arbitrary real r. If zero group, a=0 implies all weights zero, and scale rescue requires a separate seed rule. This formulation allows scale learning before and after closure. Gradients through the projection or alternating retraction must be defined explicitly. Merely naming it exact-gradient training is inadequate: the loss gradient is exact at the current dense point, but the projected update is nonlinear and nonsmooth. At endpoint a differentiable path cannot continuously flip a nonzero individual sign while keeping the group binary, except by collapse through zero; direct sign moves or STE remain useful.

Measure distance-to-lattice along schedule: `e_close = ||w-Q(w)||²/||w||²` and activation-weighted variant. For a fixed r and cap c, all magnitudes near saturation when n c²-r² is small; specifically sum(c²-w_i²)=n c²-r². Since (c-|w_i|)² <= c²-w_i², error to c sign(w) is bounded above by n c²-r². This gives a directly checkable closure certificate before FP16 rounding, without claiming loss guarantee. Loss error can still be large if directions are sensitive; for L-Lipschitz gradient, `L(w+d)-L(w)<=g^T d+(L/2)||d||²`. The dimension and scale of g,L are problem-specific.

Recommendation: drop the unconstrained clipping-only description; retain a normalized norm+box branch with explicit projection, hard checkpoint audit and transition to A-prime/D/E at closure. A shrinking fixed-norm cage is not a way to avoid a closing distribution shift unless it truly reaches its feasible equality and the scale is already representable. Do not spend effort preserving arbitrary parent RMS when it is not the best allowed scale.

### 1D. Candidate C: mirror steps and saturation

Let u be dual state, w=M_a(u), u'=u-eta g(w). This is not a complete update until M, scale handling and the initial dual state are specified. For a smooth Legendre map such as w=a tanh(u), open interval (-a,a) is the range at any finite u. To reproduce a binary R exactly would require u=±infinity. A finite approximation w0=(1-epsilon)a s gives squared mismatch n a² epsilon². Even though updates in dual can be exact loss gradients in the mirror algorithm, the change in w is `dw/du=a sech²(u)`; near saturation it is tiny. In terms of w, `dw/du=a(1-(w/a)²)`. Thus a saturated starting point can be exceptionally hard to move. Changing from a bounded map to clipping near the endpoint does not by itself solve this. A finite final u never guarantees C16. If the scale moves, the endpoint range moves, and the old u maps to different w. Need explicit scale update, not silently changing the feasible set in a proof of fixed-domain mirror descent.

For an exact finite saturation use M_a(u)=clip(u,-a,a). It is the derivative of convex Huber potential psi*(u):

    psi*(u)=.5u²             when |u|<=a
            a|u|-.5a²       otherwise.

The derivative is u inside and ±a outside; its conjugate is .5 w² plus indicator of box. This is a valid convex dual map with saturation, but not a smooth invertible Legendre map at the boundary. A claim relying on strict convexity of the conjugate outside the interval or a one-to-one dual inverse would be invalid. One can choose u0=a s for R, reproducing exactly. At the boundary, an inward dual update immediately changes w; outward update is clipped. If u is far beyond the boundary, even inward updates need to traverse the overshoot before w moves. Thus exact representability and favorable mobility are separate. At P, choose a>=max|w0|, u=w0, start exactly; pure KL has zero initial gradient. If a is fixed smaller than max|w0|, initialization clips and induces error. This map imposes a box, not a binary lattice. It can finish with arbitrary interior entries. A simple 1D loss minimized at 0 disproves guaranteed final saturation. Add B's norm closure or D/A hard projection. With a decreasing a, exact saturation can occur but unless norm/shape conditions hold, interior weights remain.

Mirror maps based on large powers can concentrate magnitudes under certain optimization objectives, but without an actual fixed equality or quantization constraint no finite-power rule guarantees all 128 magnitudes equal. An infinity-norm objective bounds maximum magnitude and may encourage using more coordinates; it does not imply every coordinate is on the boundary. The map `u -> argmax_w u^T w - psi(w)` with psi indicator of box (no strict regularizer) can yield a sign directly, but its value at u_i=0 is set-valued. This is no longer a smooth latent relaxation; it is a discontinuous endpoint method closely related to signs of accumulated gradient. Define tie behavior and scale. If scale is learned jointly, its gradient includes any dependence of w on a at fixed u. For tanh it is `sum g_i tanh(u_i)`; for hard clip, boundary/saturation regime contributes `sum_{|u_i|>a} g_i sign(u_i)`, with a subgradient choice at equality. At exact binary endpoints the tied scale derivative is `s^T g`.

Recommendation: do not promote C from an unspecified map to a complete experiment. Use one explicit dual map with inverse/init and endpoint tests. For the release warm start A-prime/D are simpler ways to control margin mobility. A smooth mirror branch can be a useful P conversion relaxation, but it must have a separate exact closure step. Theory for fixed convex domain is not theory for learned group scales or nonconvex distillation.

### 1E. Candidate D: direct sign updates with a budget

For fixed a>0, a sign flip i changes q by `d=-2a s_i e_i`. Let g=dL/dq at current q. First-order price is `g^T d=-2a s_i g_i`. Only s_i g_i>0 is first-order favorable. Larger absolute gradients on infeasible directions (s_i g_i<0) must not be ranked as favorable moves. A local L_i-smoothness bound gives

    L(q+d)-L(q) <= -2a s_i g_i + .5 L_i(2a)²
                 = -2a s_i g_i + 2 a² L_i.

A sufficient decrease condition is s_i g_i > a L_i. This differs from asking whether an ordinary SGD displacement crosses a threshold. D can propose a full flip even when eta g is tiny; it still cannot make an actually unfavorable flip beneficial. For a quadratic with Hessian H, the bound is exact with H_ii in place of L_i. For a set I, cross terms `4a² sum_{i<j} s_i s_j H_ij` can reverse the sum of individually beneficial moves. A budget limits risk but is not proof that largest updates collectively improve loss. Use curvature, groupwise exact quadratic scoring, or actual objective accept/reject. Reusing a noisy minibatch for proposal and acceptance may bias accepted changes; log a held-out stream, not the final benchmark test. Direct loss evaluation for proposed training moves is a future experiment, not performed here.

Scale refit can be integrated exactly for a local reconstruction objective. Suppose H SPD and `r=s^T H w`, `d=s^T H s`, and choose a=r/d if r>=0. With unconstrained signed scale the objective is invariant to simultaneous sign reversal, so canonicalize afterward. Minimizing over real a gives

    J*(s)=.5 w^T H w - .5 r²/d.

For a proposed s'=s-2s_i e_i,

    r'=r-2s_i (Hw)_i.
    d'=(s-2s_i e_i)^T H(s-2s_i e_i)
      =d-4s_i(Hs)_i+4H_ii.
    J*(s')-J*(s)=.5(r²/d-r'²/d').

If the constraint is a>=0 without allowing a global sign gauge change, replace r² by max(0,r)². If using a16 evaluate J at the nearest feasible scale to the real optimum, comparing adjacent FP16 values as needed. This is exact for the declared quadratic, not for a nonlinear LM loss. I checked this identity against direct recomputation for every one of 128 possible flips with a deterministic random SPD Gram matrix; maximum absolute numerical error was 4.27e-14 in FP64. The test was algebra only. It also gives a way to rank changes by scale-refitted cost rather than gradient magnitude. A method that refits only the old s then prices new signs at the old a is a different approximation; both are valid comparisons but should not be confused.

For actual global loss use a current a and a local Taylor expansion in both sign and scale. If g_a=0 at a true continuous scale optimum, the envelope theorem removes the first derivative through a*(s) locally, but signs are discrete, so the finite jump can change the optimum materially. Reoptimize proposed scales before actual acceptance. Restrict each group to one or a few flips per proposal to control cross interactions, then consider multiple-group coupling. Define a trust rule using predicted vs observed reduction and a deterministic rollback for harmful batches. Do not call this exact PV-Tuning: the project variant has learned group scales and a different scalar constraint.

R start: take stored signs/scales unchanged. Forward matches exactly. If scale refitting occurs before the first recorded checkpoint, it can already change the model; record the true pre-refit baseline. D can move a sign in its first proposal without a latent crossing barrier. If no proposal is favorable, remaining at current state is a correct local outcome, not necessarily an optimizer defect. At a=0 sign flips have no effect; E or explicit nonzero scale proposal needed.

P start: cannot represent the original in the binary state. Start Q(w0) or F(P), with projection error stated. D has no loss-preserving exact start from generic P. End: every step is C16 if scales cast and signs always ±1. Rollback/export must use exactly that state. No final rounding sign loss. Full-precision scale masters and optimizer accumulators are allowed only as training state. Tied s is changed once, with gradient sum from both roles. Do not permit a scale refit separately for lookup and classifier.

### 1F. Candidate E: scale-only training

Let fixed s and train real a with forward a16 s if deployment fidelity required. The group has one continuous degree of freedom before scale serialization and zero sign degrees. Differential `dq=s da`, hence

    dL/da = g^T s.
    d²L/da² = s^T H_loss s (for twice differentiable loss).

For positive a, parameterization a=exp(theta) gives `dL/dtheta=a s^T g`; a=softplus(theta) gives sigmoid(theta) s^Tg. Both prevent negative scale, but zero is only a limit. Direct signed a has gauge redundancy and can pass through zero, flipping the meaning of all signs at once. If starting R with positive scale, direct unconstrained or positive mapping with exact inverse preserves the start if numerically representable. To stay faithful use FP32 master, FP16 forward with suitable STE for rounding. If exact constraint of positive a including zero is needed, project the master, not just silently clamp the forward. First-step motion exists if signed gradient sum is nonzero and scale crosses a serialization cell. If sum cancels, individual weights may want to change but E cannot. On a diagonal quadratic, solving each group scale exactly often makes all further same-objective E updates zero. This is informative negative evidence about available continuous degrees of freedom, not proof the model cannot improve using signs.

R start exact; P start with sign(w0) and mean or H-optimal scale, not exact unless already feasible. End exact with hard-scale forward. E is the most useful first diagnostic baseline: it tests how much recovery is available without rearranging any binary code. For N=1.72B, approximately N/128=13.44M scales before group padding and norm exception. Count no additional deployment parameters if they replace existing scales. Do not compare to a two-scale head: that adds a new degree of freedom. E can also be the polishing stage after sign selection or hard closure.

### 1G. Candidate F: sequential correction as initialization

Consider one row reconstruction loss `J(delta)=.5 delta^T H delta`, H SPD, current unconstrained row w, desired quantized entry q_i. Constrain delta_i=q_i-w_i=e. Lagrangian `J(delta)+lambda(e_i^T delta-e)`. Stationarity `H delta+lambda e_i=0`, so `delta=-lambda H^-1 e_i`. Constraint gives `lambda=-e/(H^-1)_ii`. Thus

    delta=e H^-1 e_i/(H^-1)_ii.
    cost=.5 e²/(H^-1)_ii.

Update remaining unfixed weights using this delta, fix entry i, and continue with remaining free coordinates using the appropriate restricted inverse (or equivalent Schur update). This is the exact local optimal compensation given one constraint and a quadratic. It does not say the best ordering or sign choices solve the global binary problem, and it does not establish a nonlinear distillation bound. It provides the mathematical core of the F initialization regardless of the implementation provenance of GPTQ-like methods. H singular requires damping or a carefully defined pseudoinverse and feasibility check. With fixed scales, q_i is one of ±a, choose closest under the one-coordinate cost. The optimal choice for that single step is nearest value in scalar distance, but choosing scale jointly across a group is coupled. If scale is recomputed after earlier signs are fixed, earlier effective q_i change and their compensation is invalidated. Either hold scales fixed through a pass, or treat all previously fixed codes plus the shared scale as a coupled constrained subproblem, recompute residual, and rerun. The latter is a new alternating algorithm, not a simple application of the original one-step derivation.

R start: if input truly decoded strict binary, using exactly the same group partition, sign convention and scales yields e=0 at every coordinate; updates are zero, so F is identity. If a compensation method uses a different block layout or resets scales, F can damage R at step zero. There is no reason to round an already valid binary checkpoint again. Use F only on P, on a proposed reconstructed continuous teacher, or in a deliberate changed-basis experiment with measured re-encoding error. For P, the sequential process yields a binary state, not an exact teacher start. Activation-aware fitting can improve a layer surrogate versus RTN, but no guarantee it improves global model or benchmark. When used before B/C, those relaxed methods subsequently move off the lattice unless their forward remains hard; the endpoint is determined by the selected A-D method. F alone can be hard-closed by design.

Tied matrix is special. For fixed input token distribution, lookup loss curvature is driven by observed token rows; output classifier curvature couples vocabulary logits through softmax. The effective model loss depends on both occurrences. If `E_in=E_out=E`, and unconstrained two-role loss is f(E_in,E_out), the tied gradient is

    grad_E = grad_in f + grad_out f.
    H_tied = H_ii + H_oo + H_io + H_oi.

This follows from chain rule for the mapping E -> (E,E). A joint Hessian approximation that only sums separate roles drops the cross terms. In a separable auxiliary reconstruction loss the cross terms are zero by construction, not a property of the real model. A rowwise GPTQ-style output Hessian built solely from final hidden states cannot certify preserving lookup quality. For tied group scales E uses the summed gradient. For D the proposed sign affects both role computations simultaneously. A proper calibration design includes token frequency coverage and rare-token/classifier gradients, not independent exported scales.

### 1H. Six-way paper check summary

| Candidate | Step zero from R | Step zero from P | First hard change condition | Exact endpoint condition |
|---|---|---|---|---|
| A, mean STE | Yes if decoded scales and signs preserved | No, explicit Q(P) | Cumulative latent threshold, or mean scale crosses FP16 cell | Hard forward with exact deployed scale |
| A-prime, independent scale | Yes with arbitrary same-sign latent margins and copied scale | No, initial projection | Sign threshold chosen independently of scale; scale gradient nonzero and cast changes | Same as A |
| B, simple cage | Yes with cap >= a0 | Yes with sufficient cap; KL initially zero | Relaxed state can move; hard state not guaranteed to move | Not guaranteed; fixed norm equality with representable cap closes |
| C, mirror | Smooth tanh no exact finite state; hard clip yes | Yes only if in range and inverse exists | Depends on map and dual inertia; often near-boundary stalls | Not guaranteed for smooth/clip; hard discrete projection or norm closure |
| D, direct budget | Yes before refit | No | Favorable accepted finite flip or refit; no shadow threshold | Hard sign and FP16 scale every step |
| E, frozen signs | Yes | No | Signed gradient sum, scale quantization threshold | Hard scale every step |
| F, sequential start | Identity only with same valid codec, otherwise new projection | No | Rounding-induced perturbation then chosen trainer's rule | Fixed-scale sequential projection, then chosen trainer's closure |

All exact statements are conditional on the tensor manifest, no hidden head copies, identical inference arithmetic and deterministic sign-zero convention. None is a theorem about reaching 90% or 99%. No finite grid guarantees a useful global minimum. The original method A is a necessary control but not the only mathematically coherent binary optimizer.

### 1I. Named paper audit: provisional source extracts

This section is built from partial primary paper/code reads, not completed audits. Original results in sections 1A-1H do not depend on these reports being correct. The following are concrete locations and algorithm differences to verify in the full pass.

**BinaryRelax**, [algorithm 1 and Proposition 2.4](https://arxiv.org/html/1801.06313). Regularize distance squared to a discrete set (or union of quantization rays). Shadow y is updated by loss gradient at current relaxed x. First phase x=(y+lambda P_Q(y))/(1+lambda); lambda increases. Second phase x=P_Q(y). The formula is obtained by minimizing .5||x-y||²+.5 lambda dist(x,Q)² and jointly choosing closest feasible representative. Finite lambda leaves residual `(y-P_Q(y))/(1+lambda)`. A differentiable loss cannot generally have a relaxed local minimum exactly on Q unless the loss gradient vanishes there, because the squared distance penalty has zero first derivative at Q. The paper explicitly hardens. Theorem 4.10 uses approximate orthogonality bounds, smoothness and diminishing steps (sum squares finite, further condition sum infinite for stationarity conclusions); not a theorem for a changing, FP16-serialized scale lattice. Reported image experiments include CIFAR ResNets and ImageNet, not a binary tied LLM. Closest to B as a continuation method, but the actual algorithm approaches a distance-to-Q penalty rather than a shrinking symmetric box. Its second phase addresses exactly the closure defect we found. The original code and complete proof have not been audited; no result used as quantitative transfer evidence.

**ProxQuant**, [paper sections 3-5 and appendix B](https://arxiv.org/html/1810.00861), [regularizer code](https://raw.githubusercontent.com/allenbai01/ProxQuant/master/reg.py), [training code](https://raw.githubusercontent.com/allenbai01/ProxQuant/master/main_binary_reg.py). Optimize L(w)+lambda R(w). Eager prox update `prox_{eta lambda R}(w-eta grad L(w))`; W-shaped penalty for fixed ±1 can be written `sum ||w_i|-1|`. Derive scalar prox in sign chamber: choose magnitude v>=0 minimizing `.5(v-|y|)² + t |v-1|`. Let d=|y|-1. The solution is `v=1+sign(d)max(|d|-t,0)`, with nonnegative v; assign sign(y) or deterministic tie at zero. It pulls interior magnitudes toward 1 and exterior down, unlike a cage that only clips. The direct fixed-level code uses sign multiplication, so exact y=0 under torch.sign(0)=0 can leave 0 instead of one of two minimizers unless handled outside this path. Adaptive binary code uses shared center fitting via mean/median-dependent choices; this is not automatically the g128 grouping rule. Code includes lazy prox before forward, saves and restores unconstrained weights before optimizer step; eager path optimizer step then prox. Paper's smoothness/prox-gradient convergence applies to eager exact proximal steps, not any Adam/lazy variant. In CIFAR-10 ResNet-20 comparison, FP error 8.06%, BinaryConnect 9.54%, PQ-B 9.35%; warm-start 300 epochs, hard at 200. Not an all-weight g128 language model. A useful alternative B closure penalty is distance in L1, with learned group centers treated as an alternating step; finite prox can reach the exact fixed magnitude, but jointly learned scale needs a fresh derivation. No direct generalization theorem used.

**ASkewSGD**, [constraints and theorem 1](https://arxiv.org/html/2211.03741). Paper defines a superlevel neighborhood of fixed discrete values with scalar smooth polynomial-type constraint psi_epsilon. It picks velocity minimizing distance to negative gradient subject to `v_i psi_i' >= -alpha psi_i` for active constraints. If unconstrained negative gradient meets the inequality, retain it; otherwise `v_i=-alpha psi_i/psi_i'` with clipping near midpoint singularity. Midpoint direction chosen by convention. Update `w'=w+gamma v`. Theorem for fixed epsilon requires each sample loss d-times continuously differentiable and Lipschitz gradients, positive steps with infinite sum and finite squared sum, and epsilon no larger than minimum adjacent gap^4/16. It asserts approach to constrained KKT set at that epsilon, not a global binary optimum for an annealed schedule. Table 2 reports W1/A32 CIFAR-10 88.98 vs FP 89.46 and TinyImageNet 50.23 vs56.46; projected gradient 71.34/11.78 in the respective tests. Last fully connected layer is kept full precision in described low-bit setup. A disconnected shrinking neighborhood of each ±a is different from B's global interval; it actively drives toward endpoints, potentially prevents transitions once islands separate. A useful comparison to norm closure, not a proof for jointly learned scale. Complete code not obtained.

**PV-Tuning**, [method and Appendix A pointers](https://arxiv.org/html/2405.14852), [optimizer](https://raw.githubusercontent.com/Vahe1994/AQLM/main/src/pv_optimizer.py), [driver](https://raw.githubusercontent.com/Vahe1994/AQLM/main/finetune.py). P step optimizes values holding assignments, V step optimizes assignments holding values. Exact alternating minimization cannot increase the objective because each prior point is feasible. The paper's linearized V majorizer `L(y)+g^T(x-y)+L_smooth/2||x-y||²` preserves monotonicity when minimized under the fixed codebook with the stated smoothness constant. A grid-coarse stall is expressly identified: a valid conservative update may be below a cell. Current code has configurable code/scale/nonquant parameter optimizers, separate code LR, delta decay (shadow versus direct-like update), update fraction cap, and logs code-change fractions; inspect exact discrete backend before equating it with D. Default maximum code change per step is .01 per tensor in inspected driver, not a universal optimal binary group budget. Main published LLM experiments involve larger additive/codebook models, not verified g128 tied binary at <=3B. D's explicit refit-aware quadratic formula is a scalar specialization in spirit, not their proven full algorithm. No assumption that the current main branch reproduces the paper's experiments. The source has 1619 rendered lines; full appendix audit incomplete.

**Quantized-Endpoint Descent (QAR)**, [section 4 and appendix B pointers](https://arxiv.org/html/2609.21834). Direct endpoint transitions avoid persistent shadow weights. For code spacing h, update direction u, feasible indicator M, a uniform one-cell crossing probability is `p=min(1,eta M|u|/h)`. Group power score rescales p using normalized feasible gradient powers. If h=2a for binary, only opposite endpoint possible. Conditional expected change for a coordinate-smooth loss has first-order term `-p h sign(u)g` plus second-order `p L_i h²/2` (assuming the proposed descent direction). For uniform p below 1, expected first-order motion equals the nominal continuous step but expected quadratic penalty scales as eta h, not eta². Coarse jumps therefore remain costly at tiny learning rates; unbiased expected displacement is not expected loss descent. The finite-grid bound is on feasible gradients with residual floor, not unconstrained zero gradient. The paper's actual 0.5B Qwen and 3B Llama tests are 2/4/8 bits, not one bit. Table 1 Llama3.2-3B after 10000 steps at 2 bits: QAT 30.53 average and Wiki PPL779.54; QAR31.81 and393.14. This is a modest average improvement at extremely poor absolute performance. Not evidence that direct endpoint methods solve binary LLM retention. D should test curvature-aware deterministic ranking and stochastic routing separately. Proof transfer to adaptive shared scales and a two-point grid unverified.

## 2. Factorization, rotations and binary-training papers

### 2A. Accounting convention and exact projection

The named literature extracts in sections 2B-2K come from partial primary reads, with the missing material identified in section 0. They are a verification ledger, not a complete literature audit. The exact format tests and derivations below are independent of those extracts. A factor's bit width is not the original matrix's bit width, and the body bit width is not the whole model's bit width.

Let W be m by n. A model using N unique original coefficients has a true payload ratio

    b = (sum of all deployed packed payload bits
         + sum of all deployed scale, centroid, gain and bias bits
         + sum of all deployed index, mask, transform and padding bits) / N.

Count a tied matrix once in N and each physically distinct stored copy once in the numerator. A separately stored output-side scale counts even when the sign array is tied. Also report total actual file bytes including headers, tokenizer and padding, separately from learned tensor payload. Rank, layout and other metadata are not free, although a fixed architectural manifest need not be charged repeatedly per weight. Training-only tensors, optimizers, teachers and initialization projectors are not deployment payload. FP16 and BF16 are both 16 physical bits but different value lattices. A model with 18% of its parameters still FP16 and the remaining 82% at 1.0 bpw has at least 3.70 bpw, before scales and other overhead; this illustrative fraction is not a measured inventory of any specific release.

For a dense target group w of length G=128, the nearest unweighted strict binary group solves

    min_{s_i in {-1,+1}, a>=0} sum_i (w_i - a s_i)^2.

At fixed a>0, each coordinate minimizes its squared error at s_i=sign(w_i). Then the objective is

    sum_i w_i^2 - 2a sum_i |w_i| + G a^2.

Setting its derivative to zero gives a=mean |w|; the FP16 nearest representable scale minimizes the resulting scalar quadratic. Ignoring scale rounding, the squared distance is

    ||w||^2 - (sum_i |w_i|)^2/G = G Var_i(|w_i|).

With rounded scale a_q the additional error is G(a_q-a)^2. This applies to the dense reconstruction from any factorized representation, regardless of how cleverly its factors were fitted. It is not a statement about task loss. Under a positive semidefinite activation metric, the best signs need not equal the raw weight signs (see section 1G). For independent zero-mean Gaussian entries, E|w|=sigma sqrt(2/pi), E w^2=sigma², and the asymptotic relative squared projection error is 1-2/pi=0.36338. This is a model of magnitudes, not a lower bound for actual trained groups; equal-magnitude weights have zero projection error. For finite iid groups the expected numerator divided by G sigma² is (1-1/G)(1-2/pi), because E[(sum |w|)^2]=G sigma²+G(G-1)2 sigma²/pi. This is a ratio of expectations, not expectation of the ratio.

A real dense matrix generated by a binary product, sum, or rotated basis belongs to the exact target set only if every group has equal absolute magnitudes representable as one finite FP16 value. Zero entries are allowed only if the entire group is zero. In particular a rank reduction is neither required nor implied by dense sign coding: a square Hadamard matrix has full rank and only two values. We should not conflate algebraic rank compression with binary alphabet compression.

### 2B. LittleBit and LittleBit-2

Partial primary reads: [LittleBit](https://arxiv.org/html/2506.13771), [LittleBit-2](https://arxiv.org/html/2603.00042), [implementation](https://github.com/SamsungLabs/LittleBit). LittleBit uses reduced-rank binary factors with scale vectors. LittleBit-2 uses two binary-factor paths and more elaborate initialization with joint orthogonal rotation and scale decomposition. A generic single path has

    W_hat = diag(a) S diag(c) T diag(b),
    S in {-1,+1}^{m*r}, T in {-1,+1}^{r*n}.

Each factor is binary, while each reconstructed entry is a weighted sum of r signed terms. With one 16-bit number for each element of a,b,c, one path requires r(m+n)+16(m+n+r) bits, before padding. Two independent paths with these vectors require 2r(m+n+16)+32(m+n) bits, agreeing with the form in LittleBit-2 Appendix H for equal ranks. If output or input scale vectors are shared, subtract only their actual shared payload. For square d by d, equal-rank two-path coding at 1.125 bpw requires

    4rd+32r+64d <= 1.125 d²,
    r <= (1.125 d² - 64d)/(4d+32).

This bound is for the matrix alone. The two-path rank is at most min(m,n,2r). At d=2048, r <= floor((1.125*2048²-64*2048)/(4*2048+32)) = 557. No comparable rank ceiling applies to a strict dense binary matrix. Embedding/head and normalizers at 16 bits add whole-model overhead. An exactly equal storage comparison must include them rather than quoting the factor rank ratio.

LittleBit reports KL distillation with a hidden-feature MSE term (weight 10 in the inspected method), WikiText-2 and C4, sequence length 2048, five epochs, Adam with betas .9/.999, and a cosine schedule with 2% warmup. The training uses a smooth surrogate derivative for binary factors. A source-complete token count, exact optimizer settings for each size and full configuration audit were not obtained. Neither the factorization nor its scales amount to the project's g128 codec.

### 2D. TWLA and post-training ternarization of Qwen3-4B

Partial primary reads: [TWLA](https://arxiv.org/html/2606.13054) and [Qwen3-4B application](https://arxiv.org/html/2609.01962). TWLA's asymmetric ternary reconstruction can include a center, an amplitude, a ternary core, and selected residual terms. An abstract representative formula is

    W_hat = mu + alpha_0 T_0 + alpha_1 M ⊙ T_1,

where T entries are -1,0,+1 and M selects residual entries or blocks. The Qwen application describes more than one mask class. The offset mu is not allowed in a strict symmetric group, zeros are a third value, and residual terms create more levels. The 1.58 ideal entropy of a ternary alphabet is log2(3)=1.58496 bits per symbol; a fixed independent per-symbol integer encoding uses 2 bits. Block packing can approach the former with padding/metadata. Add every offset, amplitude, mask, residual symbol, and rotation representation to storage. For a group of G, with a p fraction carrying extra ternary symbols and 16-bit center and two amplitudes, an illustrative lower accounting floor is log2(3)(1+p)+48/G plus any mask representation, not a verified TWLA file formula. With a fixed independent arbitrary mask and no structural pattern, the mask alone has combinatorial coding cost log2 binomial(G,pG) bits per group in an enumerative representation. Sparse structured masks can be cheaper. Do not assume zero cost.

TWLA additionally uses structured transforms and activation quantization variants. The 4B study applies the method to an existing rotated checkpoint, describes 64 by 2048 calibration positions, multiple mask classes with [2,2,1,1] ordering, and 15 coefficient refinement steps. It reports 252 targeted linears, roughly 3.633B targeted weights, and additional tensors including vocabulary and rotation tensors. The reported artifact sizes are 3.96 GiB and 2.659 GiB for different packaging choices; neither is 1.58 physical bits per original parameter over the whole model. The full manifest, quantization precision of each tensor, and distinction between unique tied versus physically separate vocab tensors require actual file inspection. Do not infer tying from the model family name. No training of the full decoder established from these PTQ descriptions.

### 2E. Kashin and overdetermined bases

Partial primary reads: [structured Kashin](https://arxiv.org/html/2609.11687), [overdetermined basis](https://arxiv.org/html/2404.09737). The older method uses a redundant representation of the form X=U+Q_1 V Q_2^T. The later structured work uses fast orthogonal transforms and an iterative truncation/residual procedure. Its theorem describes a residual contraction of form (1-beta)^(k/2) under its uncertainty principle assumptions, with beta tied to the transform's uncertainty parameters; the proof and constants are not certified in this review. The theorem is about finding bounded coefficients in an overcomplete system, not about a direct equal-magnitude representation of X. If both U and V have one coordinate per original coordinate, quantizing both at two bits already costs 4 bits per original coordinate, not two, plus scale/centroid and transform information. An implicit transform seed may be small but its computation is not zero. Quantizing both at one bit still costs 2 before any scale. A genuinely overcomplete representation increases coefficient count; to be below 1.125 total bits it must use an alternative compression or reduce other degrees of freedom. It cannot be quietly substituted for the dense format.

Older small OPT experiments (provisional): OPT-125M FP PPL42.01, 4-bit48.92, mixed scheme44.88; the mixed method assigns different bit widths and representation kinds. The structured paper reports Pythia-1.4B Wiki14.72 vs16.49, OPT-1.3B16.47 vs17.19, in the inspected 4-bit comparison. For the three reported OPT accuracy values 41.36,71.00,59.75 versus40.59,70.68,58.32, equal task weighting gives 169.59/172.11=98.54% retention. Good 4-bit evidence if replicated; not 1-bit evidence. These paper extracts do not provide a verified <=3B strictly binary result, full embedding/head storage, or implementation audit. Calibration and convergence details, exact code and experiment settings remain outstanding.

A bounded coefficient representation may inspire a sequence of offline residual corrections before our final projection. The dense matrix that is obtained by adding transformed terms still generally has unequal absolute magnitudes. There is no free extra basis in the codec. The theorem for overcomplete dictionaries does not imply that a square coordinate basis can represent arbitrary matrices as equal-amplitude signs without distortion. The group projection error of 2A is an exact counterexample for a fixed W and coordinate system.

### 2F. PBBQ and SDQ-LLM

Partial primary reads: [PBBQ](https://www.mdpi.com/2079-9292/15/4/819), [SDQ-LLM](https://arxiv.org/html/2510.03275), [SDQ code collection](https://github.com/Dreamlittlecat/LLM-Quant-Factory). PBBQ is primarily a PTQ procedure for reorganizing and propagating block quantization errors, not a new binary alphabet. It reorders columns during compression and attempts to compensate subsequent blocks. The inspected inference claim reverses the reordering. That can have zero deployed transform cost if the final tensor is stored directly in its original order, but the quantization groups in that final order must also be the intended groups. A permutation followed by contiguous group coding, then inverse permutation, generally makes each resulting physical row group contain coefficients from multiple scale groups. Inverse permutation is not free in *our* format unless it preserves grouping or is implemented as a legitimate model-wide reparameterization. PBBQ inherits the underlying quantizer's side information. Provisional 7B PPL table: teacher5.47, GPTQ 2-bit60.45 to47.69 with PBBQ, BiLLM nominal1.08 32.48 to25.51, ARB16.44 to12.82. None is a strict g128 small-model result. The code and data manifest were not audited. Useful idea: test whether a better ordering of the *offline search* helps, while writing the final signs and scales in the same original coordinate groups.

SDQ uses a sigma-delta error shaping procedure, spectral resampling/oversampling and calibration-dependent compensation. The key storage check is independent of the paper's terminology: if N coefficients are encoded into qN symbols, each at b physical bits, raw payload is qb bits per original coefficient. At oversampling factor two, two binary symbols per original coefficient cost two bits and two ternary symbols cost at least 3.1699 ideal alphabet bits, unless further compression reduces the actual stored sequence. If the stored object is instead a downsampled reconstruction, that reconstruction's alphabet must be examined; it is not automatically binary. This is a conditional accounting identity, not an accusation that the paper misreports its format. Its nominal width table cannot resolve the question without the encoder, decoder and file. The method description excludes embedding/head. Provisional smallest-model Table 1 PPL, FP to nominal 1.58 version: OPT1.3B14.62 to38.24; OPT2.7B12.47 to20.30; Llama3.2-1B9.75 to298.31; Llama3.2-3B7.81 to31.65. No benchmark retention from those numbers. C4 calibration is described; the exact calibration manifest, tensor layout, oversampling serialization and code paths were not obtained. No basis for calling it a dense binary deployment. Use the error shaping idea, not the deployed spectral representation, in a future fixed-group F variant.

### 2G. NanoQuant: factor and scale audit

Partial primary reads: [NanoQuant](https://arxiv.org/html/2602.06694), [code](https://github.com/SamsungLabs/NanoQuant). Direct raw acquisition succeeded for [main.py](https://raw.githubusercontent.com/SamsungLabs/NanoQuant/main/src/nanoquant/main.py), [hub.py](https://raw.githubusercontent.com/SamsungLabs/NanoQuant/main/src/nanoquant/modules/hub.py), [linear.py](https://raw.githubusercontent.com/SamsungLabs/NanoQuant/main/src/nanoquant/modules/linear.py), [compress_model.py](https://raw.githubusercontent.com/SamsungLabs/NanoQuant/main/src/nanoquant/core/compress_model.py), and portions of the block optimizer and ADMM source. The factor class has continuous latent binary-factor parameters, independent scale parameters, optional intermediate scale, and pre/post scaling. This is not a single dense g128 binary linear. A single path still contains two factors. The paper's sign-vector decomposition subroutine is a useful candidate for a single binary matrix, but the inspected deployed class is not such a converter.

The factorization solves a calibrated, regularized approximation, with alternating least squares and ADMM-style binary projection. To illustrate the normal equation without relying on a paper theorem, for fixed V and target A consider

    min_U .5||A-U V||_F² + .5 rho||U-Z+Lambda||_F² + .5 lambda||U||_F².

Gradient is (UV-A)V^T+rho(U-Z+Lambda)+lambda U. Equating to zero and transposing gives

    [V V^T+(rho+lambda)I] U^T = V A^T+rho(Z-Lambda)^T.

This uses V of shape r by n. The implementation may transpose its V storage convention. A binary/scale projection updates Z, and dual accumulation follows. In a scaled two-factor real representation, multiplying U by c and V by 1/c leaves UV unchanged. Equating Frobenius norms yields c= sqrt(||V||_F/||U||_F), valid when both norms nonzero. It changes conditioning but not the real reconstruction before quantization. Scale and sign variables must be distinguished in that derivation.

Inspected code defaults include 400 outer iterations, 5 inner iterations, regularization .03, factor learning rate 1e-5, 8 epochs, global learning rate 1e-5; hub calibration default seed 0, WikiText-2, 128 samples, shrinkage .4. A 128 by 2048 calibration selection has at most 262144 selected positions before repeats and padding. It is not the total number of processed training tokens. The local block optimizer uses a reconstruction objective with weighting; the global teacher-KL phase selects named scale parameters, holds the binary signs fixed, and uses AdamW and cosine scheduling. The inspected linear class uses BF16 factors/scales in its indicated path and a binary STE with zero assigned +1. Exact run-specific CLI flags, complete configuration, optimizer step counts and evaluated checkpoint manifests remain missing. A default in source is not evidence the paper used that value.

Important code-level question: the inspected SVID power iteration uses an epsilon argument but its normalization path needs checking at all-zero residual. Dividing by a zero norm yields undefined output unless a caller guard exists. This is a candidate defect, not a reproduced bug or evidence it affected results. Add an explicit zero residual case to our own synthetic tests. The paper's reported small-model perplexity experiments were located but not transcribed as a certified complete set. No true ten-task accuracy or matched dense binary result is established by this partial audit. ### 2H. RaBiT, single binary matrices and Boole

Partial primary reads: [RaBiT](https://arxiv.org/html/2602.05367), [repository](https://github.com/SamsungLabs/RaBiT), [main.py](https://raw.githubusercontent.com/SamsungLabs/RaBiT/main/main.py), [common utilities](https://raw.githubusercontent.com/SamsungLabs/RaBiT/main/utils/common.py), [quantization utility](https://raw.githubusercontent.com/SamsungLabs/RaBiT/main/quantization/utils/quant_util.py), [packer](https://raw.githubusercontent.com/SamsungLabs/RaBiT/main/quantization/utils/binary_packer.py). The actual low-bit layer classes and backward kernel are still missing from the completed audit. The paper's residual decomposition uses independently scaled binary matrices, with sign choices for subsequent paths based on the residual. The single-path matrix can be written

    W_1 = diag(a) S diag(b), S_ij in {-1,+1}.

For K independent paths, the unpadded storage is Kmn+16K(m+n) bits if all scales are 16-bit and no shared side tensors. For K=1, this can be near one bit, but the magnitudes |a_i b_j| generally vary within each group of 128 columns. To coincide exactly with the target, the |b_j| must be constant in each target group for all nonzero rows, and the products must be representable in FP16. If groups span rows instead, the corresponding magnitude constraints change. Multiple paths usually cannot be collapsed without projection. RaBiT's main small results are residual two-path models, not proof of single-path dense binary quality.

Function-aware initialization scales W according to input and output statistics before decomposing, and folds back the inverse scales. That is an offline objective change, not magic extra degrees of freedom. For separable row and column nonnegative weights p_i,q_j, solve

    min sum_ij p_i q_j (W_ij-a_i S_ij b_j)^2.

At fixed a,b positive, optimal S is sign(W); at fixed S,b, differentiate in a_i to obtain

    a_i = [sum_j q_j W_ij S_ij b_j] / [sum_j q_j b_j²].

Similarly b_j=[sum_i p_i W_ij S_ij a_i]/[sum_i p_i a_i²]. If denominator zero, that scale is unidentifiable and a deterministic policy is needed. This is a weighted rank-one approximation of |W| with alternating updates. A leading singular vector initialization or row/column mean magnitude can be used, but neither is equivalent to free per-group scales. For our format with one scalar for the 128 entries, independent diagonal weights h_i give instead

    a = sum_i h_i s_i w_i / sum_i h_i,

then project to nonnegative finite FP16, or simultaneously reverse all group signs if canonicalizing a negative continuous scale. This is the exact diagonal-weighted scale update, not an approximate one; full Hessian requires section 1G. A negative stored scale is mathematically redundant for one independently encoded group (except finite arithmetic corner cases), not proof of an optimizer's internal parameterization. If two consumers share signs but have different scale signs, simultaneously canonicalizing the signs cannot make both scales positive without changing one consumer. This matters for Boole.

Provisional RaBiT training description: 200M combined WikiText-2/C4 tokens, six epochs, Muon, teacher KL and hidden-state MSE; weight gamma100 in described Llama setting and gamma0 in Gemma setting. Exact Qwen settings and whether token count denotes unique or processed positions remain unverified. Code shows optional calibration, freezing/excluding embedding and lm_head in inspected path, default two residual paths, model weight tying on load, and strict=False in one load path. A non-strict load that warns rather than fails is a risk for a checkpoint parity test, not evidence of incorrect published metrics. Require zero missing or unexpected tensors on our own loader. ### 2I. Retie algebra for Boole and the two-scale ablation

Independent result. Suppose a group has common signs s and two scalar magnitudes u,v, one for embedding and one for readout. For a weighted squared reconstruction loss using positive coefficients h_in and h_out (summing relevant diagonal sensitivities within the group), one scale a gives

    f(a)=h_in(a-u)^2+h_out(a-v)^2.

Differentiate: f'(a)=2h_in(a-u)+2h_out(a-v). Thus

    a*=(h_in u+h_out v)/(h_in+h_out).

Substitute a*-u=h_out(v-u)/(h_in+h_out) and a*-v=h_in(u-v)/(h_in+h_out). The minimum penalty is

    f(a*)=h_in h_out/(h_in+h_out) (u-v)^2.

Additional FP16 rounding cost is (h_in+h_out)(a_q-a*)². If the constrained nonnegative scale is used with fixed signs, clamp to zero when a*<0, or compare global sign reversal plus the appropriate positive scale. If the two signed scales have opposite signs, the two decoded matrices oppose each other in that group; there is no exact single-magnitude solution unless both consumers are equal or the discrepancy is immaterial to function. For an actual network loss, off-diagonal correlations, interactions and input/output paths invalidate the scalar surrogate's exact global optimum. But the reconstructed matrices still cannot both be identical to two different original matrices.

Consequently Boole is a valuable reference but not an exact step-zero release starting point for the strict format unless the two scales happen to agree everywhere (after handling orientation). Its additional .024 bpw in the project brief is not merely padding: it purchases extra degrees of freedom precisely in a large, dual-role tensor. The fair route is to report original Boole as a separate codec; retie by a prespecified rule; measure the immediate loss; then train the resulting strict student. Never compare post-training retied Boole to the original 85.9% as though no conversion happened. Estimate h_in/h_out from a future calibrated tied-objective sensitivity calculation, or run simple equal-weight mean and magnitude alternatives. Do not choose the best scale by observing the final test answers. Treat the one-scale and two-scale variants as a controlled scientific study of the representation restriction, not as an alternative product scoreboard.

### 2J. Actual packer comparison and numerical checks

A narrow source-code fact was independently checked: the historical LittleBit unpacking code at [933857e](https://raw.githubusercontent.com/SamsungLabs/LittleBit/933857e/quantization/utils/binary_packer.py) uses a left shift in its bit extraction where the [current version](https://raw.githubusercontent.com/SamsungLabs/LittleBit/main/quantization/utils/binary_packer.py) uses a right shift. I reconstructed these operations on synthetic arrays, with lengths 1,31,32,33,128,129; right-shift errors were 0 in every case; historical left-shift errors in the particular sampled arrays were 0,18,15,19,66,50. ### 2K. Rotation folding: exact conditions, not just a change of basis slogan

Independent algebra. Adopt row-vector activations x and linear convention y=x W^T. Suppose a global orthogonal R defines a changed residual basis x'=xR. For RMS normalization without learned gains, RMS(xR)=RMS(x), so normalized row x transforms covariantly. Let D be the diagonal learned RMS gain, and choose new diagonal gain D'. To preserve a subsequent internal linear output exactly, require

    R D' (W')^T = D W^T.

For invertible D', solve

    W' = W D R (D')^-1.

An internal-to-residual output y=x W^T that must rotate to yR instead can use W'_out=R^T W_out. These identities show where a transform can be absorbed into ordinary untied neighboring matrices, without a runtime multiply. But all residual branches must agree on the same basis. Changing one layer's residual basis independently introduces a transform at its skip connection unless every crossing is reparameterized. Zero gain entries need a separate rank/feasibility analysis; do not silently invert zero.

For a genuinely tied vocabulary matrix E, embedding lookup rotates as E'=E R. A final normalized residual produces logits

    z'=norm(x) R D' (E R)^T
      =norm(x) R D' R^T E^T.

Original logits are norm(x) D E^T. With E full column rank and equality required for all residuals, the condition is R D' R^T=D. If D has distinct eigenvalues, its orthogonal eigenbasis is unique up to signs and permutations. The allowed R are signed permutations, with D' permuted accordingly. If gains have repeated eigenvalues, arbitrary orthogonal rotations within equal-eigenvalue subspaces are allowed; if D is scalar, every orthogonal R works. This is not true of arbitrary independently learned final gains. Untying E or replacing diagonal gain by a dense transform defeats the format. Bias, normalization epsilon and input scaling need consistent handling. RMSNorm epsilon does not break orthogonal norm invariance. LayerNorm also removes the mean, so an orthogonal R must preserve the all-ones subspace (and may require further affine parameter conditions).

Internal attention V/O channels can admit more general invertible changes if no nonlinearity or normalization lies between the two linear operations and all attention heads sharing a value vector are transformed consistently. Attention mixes values linearly with scalar position weights, so a common value-space map can commute with that mixing. Q/K changes must preserve dot products, obey RoPE commutation across all relative positions and respect query/key normalization and grouped-query sharing. For a plain pair of dot products q k^T, q'=qA and k'=kA^-T preserve them. With position-dependent rotation P_t, the corresponding A must commute with the relevant rotations or transform the rotation operators too. Learned elementwise Q/K gains restrict these symmetries further. A general Hadamard mix does not automatically satisfy them.

For SwiGLU with u=x W_up^T, g=x W_gate^T, h=SiLU(g)⊙u, and residual output h W_down^T, a common hidden-channel permutation P of u and g yields h'=hP; use inverse permutation in down projection. Additionally, nonzero diagonal C on u alone gives h'=hC and W'_down=W_down C^-1; the gate can remain unchanged. Multiplying g by arbitrary C is not equivalent because SiLU(cg) is not c SiLU(g) in general. Arbitrary rotations across gated hidden channels do not commute with coordinatewise multiplication. These transformations are exact over real arithmetic and may differ by rounding in finite precision. They may alter which coefficients share a scale if folded *before* quantization. After quantization a permutation of stored coefficients is closed only when it preserves the partition of coefficients into scale groups, or when group magnitudes happen to coincide. General scale folding can move coefficients out of FP16 representability; re-export rounding must be accounted for.

Internal U R and R^T V factor rotation from LittleBit differs from these decoder-level constraints: cancellation happens inside a factorization, not across a tied embedding and RMSNorm. A structured transform applied to runtime activations cannot be removed by merely declaring that its weights were rotated. Reconstructing X=U+Q_1VQ_2^T offline can remove the transform but stores a new dense X, which must be projected again to strict binary. A teacher-only orthogonal rotation of both feature vectors leaves ordinary MSE exactly invariant: ||(h_T-h_S)R||²=||h_T-h_S||². It has no benefit unless some other operation (weighting, truncation, quantization, or subset selection) makes the objective different. Nonorthogonal teacher-side weighting is legitimate as an offline loss but changes the optimization target. No runtime side tensor need survive it.

## 3. What two-value weights can store

### 3A. Definitions: information, exact recall, and benchmark retention

The literature excerpts in sections 3B-3E are built from incomplete primary reads, supplemented where explicitly indicated by prior Batch 6 navigation. The independent counting arguments in 3F-3H require no empirical literature premise. There are three different questions that should not be conflated:

1. How many distinguishable functions or parameter settings can a codec express? This is bounded by the log of the number of allowed payload states.
2. How much independently random training information can the model retrieve, under a specified query distribution, loss, and shared prior? This can be bounded in an information-theoretic experiment, or measured as a lower bound on accessible information.
3. What fraction of a particular teacher's mean task score can a student reproduce? This depends on the task distribution, scoring and structure of the function. It is not an information ratio. A student can outperform its teacher on some tasks, and lower average perplexity need not imply greater recall of arbitrary facts.

A pretrained LLM can exploit correlations across facts, compositional structure, tokenizer conventions, and an algorithm shared by both teacher and student. Its parameter count does not establish independent information about its original training corpus. A single fixed model is not a random ensemble by itself. Counting all possible teacher checkpoints only bounds universal reproduction of all teacher behaviors, not reproduction of the particular benchmark behavior of Qwen3-1.7B.

### 3B. Allen-Zhu and Li, synthetic knowledge and the 2026 memorization paper

Partial primary reads: [Physics of Language Models Part 3.3](https://arxiv.org/html/2404.05405), theorem 3.2 and empirical knowledge-capacity sections, and [Meta-memorization](https://arxiv.org/html/2611.01564), random sequence and architecture experiments. [Morris et al.](https://proceedings.mlr.press/v306/morris26a.html) was only available as a partial primary record. These are different measurement protocols; do not average their bits-per-parameter numbers.

Allen-Zhu and Li define a controlled synthetic fact universe: randomly chosen names, values, and attribute-specific value sets, with a known entropy of the generative choices. Their theorem relates the minimum size of the possible weight set to expected losses of recovering those choices. One can see the structure of the bound without needing all the paper's combinatorial constants. If names are chosen uniformly from a pool of N0 possible names and N are selected, name selection entropy is log2 binomial(N0,N), not necessarily N log2 N0. If each of K attribute values for each of N names independently selects one of D^C equally likely strings, value-selection entropy is NK C log2 D, conditional on the dictionaries. The dictionaries themselves may be random choices from a large string universe, producing an additional entropy term. They must not be counted again as independent value entropy. In the paper's theorem 3.2 the corresponding recovery losses discount recoverable information from these terms; the complete proof and asymptotic conditions have not been audited. A reported approximately two bits of knowledge per parameter under long synthetic training is an empirical observation of this experimental setting, not a lower or upper universal bound. The inspected quantization discussion indicates much greater loss for 4-bit GPTQ than for int8 in their knowledge experiment. Quantization without knowledge-targeted recovery is not the same as training a model subject to that precision constraint. It does not establish the accessible knowledge of a 1.7B real-world teacher, and its tested task is not the ten-task suite.

A useful independently derived cross-entropy bound generalizes the experimental idea. Let Z denote the random fact set, W its trained checkpoint, Q a public query or a fact index independent of the unknown answer conditional on the declared design. Let p(z|W,Q) be the readout distribution, possibly the language model's probability of the complete answer. The expected loss in bits is L=E[-log2 p(Z|W,Q)]. Cross entropy decomposes into H(Z|W,Q)+E KL(P_true||p), hence L>=H(Z|W,Q). Therefore

    I(Z;W|Q) = H(Z|Q)-H(Z|W,Q)
             >= H(Z|Q)-L.

If the readout is sequential, use the chain rule and include all conditional factors exactly once. The quantity on the right can be negative for a poor model; report the signed estimator, not a positive clip applied separately to every attribute. A trivial lower bound of zero for the aggregate is mathematically valid, but clipping every noisy attribute upward biases the estimated sum. The bound is not automatically equal to mutual information because the readout may be suboptimal. Correlated facts cannot be added using their marginal entropies as though independent. This independent derivation is one reason the synthetic experiment is attractive.

The 2026 meta-memorization paper uses random sequences with known information (reported 100-bit examples and a skewed presentation distribution). It estimates a transition in recall across a frequency-ranked set of sequences. The inspected width/depth comparison reports approximately .005 versus .01 recoverable sequences per parameter for one versus twelve layers in the tested regime, corresponding to about .5 versus 1 bit per parameter if those sequences each contribute 100 independent bits. This is conditional on its particular estimator and sampling design. Its fresh-data-switch experiment indicates that learning history can improve acquisition of new arbitrary strings, rather than simply filling fixed memory slots until capacity. The source does not provide a certified strict binary bound. Depth, learning dynamics, and distribution can affect how much of the same theoretical storage is reachable. Do not extrapolate a fitted slope to a 1.7B decoder or to an arbitrary alphabet. The complete supplements and experiment code remain missing.

The random-string method associated with Morris is also a useful control because it can compare exposure to independent held-out draws. A random fact readout can be difficult because of the language/format interface, whereas a raw random-string prediction can remove that obstacle. The primary proceedings abstract alone is not enough to certify its exact estimator or empirical numbers here. In our experiment the synthetic entropy and the lower bound above can be computed directly, without depending on a published memorization estimator's conventions. Report the gain relative to a known generative distribution as well as any train-versus-heldout likelihood comparison. Training loss differences need not be attributable exclusively to memorization when the data are not iid or the holdout has different distribution.

### 3E. Theory of the binary perceptron: what carries and what does not

Partial primary read: [A note on the capacity of the binary perceptron](https://arxiv.org/html/2401.15092), statement and proof outline. For a homogeneous binary perceptron with N weights in {-1,+1}, iid symmetric continuous random inputs, and independent random labels, each fixed nonzero weight vector satisfies a random label constraint with probability 1/2. Conditional on a fixed vector, the M independent constraints give probability 2^-M. Let Z count satisfying vectors. Linearity of expectation gives E[Z]=2^N 2^-M=2^(N-M). By Markov, P(Z>=1)<=2^(N-M). If M/N>1 by a fixed positive margin, the probability tends to zero exponentially. That is an elementary counting bound without invoking the paper's more refined theorem. The primary paper states a stronger upper capacity near .847 for its specific asymmetric random binary perceptron setting; the commonly discussed .833 threshold is not a universal bit-per-parameter theorem. Full proof and assumptions require completion. The exact threshold depends on constraint distribution and margin, and storage of labels is not a retrieval problem for arbitrary structured LLM queries. Adding one continuous scale per perceptron output does not change the sign classification of a homogeneous bias-free single perceptron if the scale is positive. Adding a scale per group instead changes the direction of the vector, and consequently the classification constraints. The simple bound then must count the allowed group-scale choices too. Width, depth, multiple output tokens and tied parameters change the function class. No extrapolation of the perceptron threshold to Qwen retention is warranted.

### 3F. Exact information ceiling of the project's format

Independent counting argument. Assume N is divisible by G=128; otherwise count physical padding separately. Assume scales are finite IEEE-754 binary16 values and the signs are canonicalized to positive scale with signs carrying orientation. The physical bit budget for dense matrices is

    B = (N/G)(G+16) = 1.125 N.

For an illustrative N=1.72e9, B=1.935e9 bits=241.875e6 bytes (decimal MB). The actual Qwen unique-tensor parameter count, gains, any padding and fixed metadata must be counted separately. The example is not a new header audit. If 16-bit gains are retained, they either contribute to the information budget or are fixed prior constants; they cannot be counted as 1.125-bit learned parameters without qualification.

A tighter bound counts distinct decoded groups. Positive finite nonzero binary16 values have 31*1024-1=31743 encodings, including subnormals (exponents 0 through 30, excluding positive zero). Every positive scale yields 2^G distinct vectors; all sign assignments at scale zero yield the one zero vector. Negative scale encodings add no distinct real vectors because negation of all signs is equivalent. NaN and infinity are excluded. Therefore the maximum number of distinct group vectors is

    C_G = 31743 * 2^128 + 1.

    log2 C_G /128 = [128+log2(31743+2^-128)]/128
                   approximately 1.11683 bits/coordinate.

This is an upper bound for real decoded weight vectors, not necessarily all distinct functions. Underflow, implementation rounding, symmetries, dead features, equal functions and identical readouts can only reduce the count. Scale sign could still matter as stored data in a noncanonical external parser, but equivalent real model parameters cannot store extra functionally accessible bits unless the runtime treats the representation differently. In the intended ordinary linear decode, the equivalence holds. This tightens the ceiling only slightly; the larger constraint is the move from multiple real magnitude degrees of freedom to one.

Now consider a random fact vector Z consisting of K independent fair bits, W the trained checkpoint sampled from the codec, and a decoder with fixed public algorithms and fixed public query indices. Data-dependent architecture choices, gains, dictionaries, tokenizer or prompts must be included as side information if allowed. Assume no independent retrieval. Then

    I(Z;W) <= H(W) <= log2 |C| <= B.

For a decoder's bit estimate Zhat_i(W), error e_i=P(Zhat_i != Z_i). Define error indicator E_i=Z_i XOR Zhat_i(W). Given W, Z_i is uniquely determined by E_i, hence H(Z_i|W)=H(E_i|W)<=H(E_i)=h2(e_i). By conditional subadditivity and concavity of binary entropy h2,

    H(Z|W) <= sum_i H(Z_i|W)
            <= sum_i h2(e_i)
            <= K h2(e),

where e is mean bit error. Since H(Z)=K,

    I(Z;W)=K-H(Z|W) >= K[1-h2(e)].

Combine with storage:

    B >= K[1-h2(e)].

This is a necessary condition for average independent-bit recall, not a sufficient condition for a finite neural decoder or optimizer. It holds regardless of training compute. If exact recall is demanded for all K independent random bits, e=0 gives B>=K. This is a different statement from an accuracy ratio. If queries themselves leak answers, the entropy must be conditional on that public side information; if answers are correlated, K must be replaced by the appropriate joint entropy and a suitable distortion model.

For an illustrative teacher that accesses K=2N independent random bits:

| Desired absolute bit accuracy | h2(error) | Required storage per original parameter |
|---|---:|---:|
| 90% | 0.468996 | 1.062009 |
| 99% | 0.080793 | 1.838414 |
| 100% | 0 | 2.000000 |

The physical 1.125 bpw budget does not rule out 90% bitwise accuracy in that artificial case. It rules out 99% bitwise accuracy in that case. The distinct-vector budget of 1.11683 likewise does not rule out 90% and rules out 99%. The largest hypothetical independent source load not excluded by the physical budget is B/[N(1-h2(e))], approximately 2.1186 bits/parameter for 90% bit accuracy and 1.2239 for 99%. If instead the goal is exact retrieval of a prespecified independent subset, maximum subset fraction at K=2N is 1.125/2=56.25%, with tighter distinct-vector ceiling55.84%. This does not contradict the 90% average bitwise result because guessing or lossy reconstruction contributes to bit accuracy. A 90% correct binary answer on independent bits is not 90% exact recall of multi-bit facts. For 100 independent bits per fact with independent error .1, full-string correctness would be .9^100 about 0.0000266; correlated errors can be very different. Measure both granularities.

### 3G. Does this rule out 90% or 99% Qwen benchmark retention?

No. Both remain undecided. The preceding argument rules out a defined source reconstruction target under a defined entropy assumption. It does not imply that the 1.7B teacher uses two independent factual bits per parameter, that every one must be reproduced to score well, or that the ten benchmarks sample arbitrary independent training facts. Conversely the counting argument cannot prove that either target is reachable. For universal reproduction of every possible 16-bit teacher at fixed architecture the student has far fewer payload states; injective reproduction of arbitrary teacher parameter arrays is impossible. But function equivalence may collapse many teacher states, and the project has one fixed teacher and a finite set of measured task distributions. There is no proven lower bound on the minimum description length of the teacher's required benchmark behavior in this architecture. Directly memorizing a public test would not count as legitimate retention; a disjoint held-out distribution is essential for a scientific claim. A high finite benchmark score, even legitimately obtained, is not proof of near-lossless model function compression.

Using the project's given teacher mean 58.24, 90% requires mean52.416, summed score524.16; 99% requires57.6576, summed576.576. From Bonsai40.88, improvements are +11.536 and +16.7776 mean task-score points respectively. The teacher's score deficit from Bonsai is 17.36. We have no measured bits-per-weight for the actual full-precision Qwen teacher. An empirical capacity of a same-size architecture trained on arbitrary synthetic facts is not evidence of its realized training-information content. Exposure counts, dataset redundancy, teacher distillation and generalizable structure matter. Sign entropy, compressibility, weight rank and scale distribution are properties of stored arrays, not recovered factual information. The teacher may store less independent information than its reachable capacity, and some information may be dispensable for the tasks. An exact estimate of teacher storage is therefore an outstanding scientific question, not a prerequisite for making the next empirical progress step.

### 3H. Critique and redesign of the planned synthetic capacity measurement

The proposed experiment is sound in broad outline but presently identifies an observed achievable-recall curve, not the architecture's intrinsic capacity. To make an informative negative result possible, the following changes should be preregistered. No training or language-model evaluation is authorized or performed in this review.

**Random source and accounting.** Define a fully reproducible generative distribution before generating a corpus. Random name selection without replacement, attribute assignments, attribute dictionaries, and randomly sampled strings have different entropy. Use independent master seeds for knowledge worlds, phrasing templates, training order and model initialization. A publicly available generator does not give the decoder permission to access the particular private draw seed. If that seed is known to the decoder, the nominal random entropy vanishes. Do not place it in runtime metadata or tokenizer training. If duplicate strings are rejected, compute entropy of the conditional draw process rather than using the naive alphabet-size formula. Distinguish entropy of the world from token count and surface-text redundancy. A name in the prompt need not be recovered, so name entropy may not belong in the answer-recall denominator. Record exactly what is supplied by each query.

**Evaluation estimators.** Use the conditional cross-entropy lower bound from 3B, in bits, for each independently randomized attribute and for full records. Record token-level loss as well as full-string exact match, greedy and optionally a prespecified sampling rule. A multi-token answer must include all answer tokens, including a fixed termination rule or an exact canonical record length. Tokenization is not a source of extra entropy: encode a fixed alphabet and compute the known probability of the whole answer, regardless of number of tokens. For correlated attributes use joint or conditional scores to avoid double counting. Score answer tokens, not an average that dilutes errors with repeated biography scaffolding. Distinguish recall of previously exposed entities with a different paraphrase from prediction for genuinely new facts. New-fact and new-entity draws provide negative controls; new paraphrases of the *same* facts test accessibility across interfaces. Use a fixed unseen phrasing set and a held-out random world to detect template memorization and accidental answer leakage. If a training-only heldout loss baseline is used, verify the distributions are matched. Report signed estimates, uncertainty intervals and per-attribute entropy before aggregate. A decline in readout lower bound is not a proof that mutual information declined; the gap to the optimal decoder is unknown.

**Storage and comparison axes.** Count unique coefficients, actual packed bytes and all learned side tensors. Include exact norm/gain handling and tied aliases. Report both recovered bits per unique original parameter and recovered bits per stored payload bit. A ternary group has a different alphabet and packing overhead, even if the same scale grouping is used. Use the same shape comparisons to isolate alphabet effects, and separate same-byte comparisons (larger binary/ternary or smaller FP) to answer engineering efficiency. Tied and untied output arms have different unique parameter counts; match both the shape and memory axes separately. Use a fixed tokenizer not trained on the random world; no learned compression dictionary external to the checkpoint. Use exact codec export for every scored checkpoint. A sign-zero convention cannot silently create a third level. Test scale subnormals, zero groups and canonicalization, and count any exceptional tensors in the numerator. The binary product arm must use one shared scale per group and one truly tied vocabulary matrix. Additional scale/head freedom is a labeled control. Do not allow the training shadow values to leak into evaluation.

**Load sweeps and architecture.** Train at multiple independent fact-load ratios K/N, not one arbitrarily chosen load. Include easy underloaded points where all representations should succeed, intermediate loads and overloaded points. For every load compare depth/width variants at roughly equal unique parameters, with several group sizes as auxiliary controls but G=128 as the product arm. More scales at smaller G may improve accessible information at increased physical cost; assess both. Test independent uniform facts, skewed exposure of the same facts, and structured compositional facts with known lower joint entropy. The latter tests algorithmic reuse and more realistic transfer, but it must not be added to the independent random capacity estimate as though each fact were equally independent. Include short random strings and multi-token strings of equivalent entropy; vary readout difficulty separately from world entropy. This design can distinguish a failure due to head/readout from a failure to encode arbitrary information at all.

**Distillation controls.** Scratch and distillation arms should see the same generated world. A full-precision teacher must not have access to the held-out random facts; otherwise the teacher becomes a side channel. Include direct supervised oracle answers, FP teacher soft targets, and mixed losses on identical text exposures. If the teacher itself fails a fact, the teacher-distilled student has a different learning signal from the supervised student. Record teacher accessible bits as well as the oracle ceiling, and optionally stratify facts by teacher confidence. The ratio of student/teacher lower-bound estimates is not a ratio of true mutual information. A distilled student can outperform a teacher on the chosen decoder; do not truncate ratios above 100%.

**Learning trajectories.** Use multiple independent optimization and data-world seeds, preferably a crossed design where each world is shared by several architectures and initializations. Equal exposure runs answer sample efficiency; train-to-stability comparisons answer attainable performance for a declared optimizer family. Neither should be mistaken for an intrinsic capacity ceiling. Prespecify checkpoints at logarithmic exposure intervals plus dense intervals around learning-rate transitions, and prespecify a plateau criterion jointly on validation likelihood and held-out-paraphrase fact retrieval. Use a sustained nonimprovement window and a tolerance based on seed variability. Never stop because an ordinary LM loss is flat while factual recall is changing. Prespecify which checkpoint is the primary final model and which is the best validation-selected checkpoint. Keep all packed checkpoints for late-collapse analysis. Include a constant or warm-stable-decay schedule control, and compare A-prime, D and E after an identical binary initialization if the goal is to distinguish optimizer limitations. Selection of schedules on a development set must be independent of the test worlds. A negative result across many optimizers is stronger evidence of difficulty, still not a universal impossibility proof.

**Statistical analysis.** Treat the independent knowledge world, not the individual correlated token, as the strongest independent replication unit. Within a world use clustered resampling by entity and attribute, paired comparisons between arms, and seed-level reporting. Track confidence intervals for the capacity curve and the load at which a prespecified retrieval threshold is crossed. Avoid pseudo-replication by treating repeated paraphrases as independent facts. Report dispersion between worlds, optimizer seeds and checkpoints. If the accessible information estimator is below the information-theoretic ceiling, distinguish a demonstrated achievable lower bound from an inferred upper bound. A lower bound of zero may mean a bad readout or a failed optimizer; it does not prove the model lacks memory.

**Interpretation matrix.** If FP fails at low load, the synthetic task or training pipeline is not calibrated. If binary succeeds at early checkpoints but fails later, existence is established and the later failure is optimization or selection. If untying or retaining a high-precision head rescues retrieval, the output restriction contributes, but the extra tensor budget is part of the intervention. If a better exact binary initializer rescues the same shape, the earlier failure was not a representational impossibility. If all optimizers fail at a load above the counting bound, that failure is consistent with an intrinsic limit but not an empirical proof of it. If they fail far below the bound, prioritize training, readout, exposure and architecture. If independent random facts fail while structured compositional facts succeed, do not generalize the random source's difficulty to all benchmark tasks. This experimental matrix should give the science scoreboard causal results even before product retention improves.

The first scientific milestone should be a step-zero and first-update theorem check, not merely a long training run.
