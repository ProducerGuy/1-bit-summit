### 0B. Three corrections to the brief

1. Multiplication of gates is nonlinear as a function of the input. The convolution block is not a succession of three linear maps. Nevertheless a diagonal gauge exists because the gates are multiplicative, and I derive its precise form below. LFM3 adds a separate sigmoid attention gate, for which the same gauge generally fails.
2. A row of a depthwise convolution has 3 or 7 coefficients, not 128. LFM2 also has 64-element Q/K gain vectors. Literal row-local grouping cannot encompass every learned weight without a layout rule. The strict format needs a frozen, shape-dependent serialization convention, not a silent exemption. If the owner insists that the original tensor's final dimension is always the row, the strict LFM claim as written is undefined rather than failed.
3. A parent may have a high average while some tasks are near chance. Equal retention can reward preservation of chance performance. A fixed transfer rule must distinguish mathematical portability, useful absolute performance, and equivalence of measured retention. No change to the ten-task product scoreboard is needed to report these distinct outcomes.

### 1B. Computation graph and cache semantics

Let h be a column of d residual activations. Let N_g(x)=g ⊙ x / sqrt(||x||²/d+eps). In LFM2, for each block i:

```
u = N_gop(h)
z = Operator_i(u)
r = h + z
v = N_gffn(r)
y = D (silu(G v) ⊙ U v)
h_next = r + y
```

For LFM3 the two residual contributions are N_postop(z) and N_postffn(y). The final normalization, called `embedding_norm` in the HF text graph, is on the output residual before the shared vocabulary head, not an extra learned input embedding transform. No independent output matrix if tied. In both graphs the SwiGLU MLP uses gate, up and down projections. The attention Q/K RMS norms act on head dimensions. The tensors are shared across heads, not one independently learned d-vector per head. RoPE follows Q/K normalization; KV sharing is GQA. Attention output is a weighted sum of values. LFM3 then multiplies each head's attention result by sigmoid(gate_proj(u)), followed by its output projection. The gate's 16×2048 learned matrix is small but the functional multiplier can affect many activation coordinates. Gate saturation is a different failure mode from linear reconstruction error.

The shortconv operator in both source implementations is

```
B_t, C_t, X_t = split(I u_t, 3)
a_t = B_t ⊙ X_t
b_t = sum over taps tau of k_tau ⊙ a_(t-tau)
z_t = O (C_t ⊙ b_t)
```

Tap ordering above denotes causal delays, not physical PyTorch cross-correlation storage order; preserve the actual kernel orientation in serialization and runtime. The prefill path left-pads for causal boundaries, with the decode path using the convolution state. The stored state must be permuted consistently under internal channel reparameterization. The LFM3 source includes sequence-boundary handling in packed prefill and a width-seven fallback when a specialized kernel cannot run. Padded/segmented streams must not mix across sequence boundaries. Runtime comparisons should compare both multi-token prefill and one-token decode, not only the dense path. These are mathematical and code-path expectations; no runtime parity test was executed.

The public llama.cpp LFM3 source creates optional post-norm pairs, rejects a one-sided pair, and separately applies attention gate sigmoid and output projection. The registered text checkpoint uses sandwich norms. LFM2's shared code also handles MoE/decision variants, so a count of all tensor creation statements overstates the selected text checkpoint. [Model code](https://huggingface.co/LiquidAI/LFM3-1.7B/raw/main/modeling_lfm3.py), [LFM3 graph](https://raw.githubusercontent.com/ggml-org/llama.cpp/master/src/models/lfm3.cpp), [LFM2 graph](https://raw.githubusercontent.com/ggml-org/llama.cpp/master/src/models/lfm2.cpp).

### 1D. LFM3 training, publication and the missing technical report

This section is based on partial primary card/release readings. Source of the following disclosures is the [LFM3 model card](https://huggingface.co/LiquidAI/LFM3-1.7B) and [release post](https://www.liquid.ai/blog/lfm3), not independently inspected training data. The card's timeline describes about 15T broad web/synthetic tokens, about 3T code/mathematics/science at short contexts, about 3T at 32K, about 0.5T at 128K and about 0.05T at 256K, rounded to roughly 22T overall. Do not interpret the sum of approximate chart labels (21.55T) as an exact accounting discrepancy. A final curated portion and specialized subsequent stages are described, including SFT (~1.75T), mixed reinforcement learning with a length penalty, multi-specialist on-policy distillation (code, math, tool calling, long context, agentic and enterprise), and agentic RL. Overlap of stages, unique versus processed token counts and exact optimization targets cannot be inferred from this chart. No teacher checkpoint hash, reproducible corpus manifest, full optimizer schedule or per-tensor quantization-aware training recipe for the original LFM3 was established. The release attributes improved outlier behavior to gating and normalization; that is not evidence that its learned weights tolerate binary conversion. An activation distribution can improve while a weight-magnitude distribution worsens.

LFM3's published context is up to 256K. The two attention types and longer kernel alter both state and long-context behavior. The released base model is a different starting point, not a drop-in teacher for the instruction-tuned checkpoint. ### 1F. Quantization and runtime scope

From selected actual llama.cpp source paths in 0C. A GGUF type name does not specify all tensors' precisions. There are at least four separate layers of support: serialization, graph loading, dequantization/kernel dispatch, and training/export compatibility. An integer codec can exist before the architecture can execute it correctly.

`ggml-common.h` defines Q1_0 with 128 sign bits and one half scale, 18 bytes. In the current `llama-quant.cpp` eligibility logic, one-dimensional tensors and shortconv kernel weights are excluded from ordinary quantization. There is also a fallback for shapes not divisible by a quantized block. The converter squeezes LFM2 conv's singleton dimension to a two-dimensional tensor; this does not fix a row width of 3. A normal matrix Q1_0 path is plausible for the FFNs, embedding and ordinary projection matrices because their input dimension is divisible by 128; the LFM3 per-head gate also qualifies by shape. A mixed file may override type choices, and vocab embedding/output rules need exact flags and per-tensor dump. Do not claim the default `Q1_0` converter assigns every eligible matrix Q1_0. The loader duplicates the tensor reference when output is absent; a reference duplicated in memory is not necessarily a second stored tensor. The target requires one stored payload and one decoded value for the tied matrix.

| Tensor kind | llama.cpp standard quantizer | Strict codec requirement | MLX / Transformers state |
|---|---|---|---|
| E and head | Matrix eligible; type may be overridden by mixed quant policy | 1 sign + FP16 scale, same decoded table in both roles | Need verified embedding quantized gather and tied output use; no strict path established |
| Q/K/V/O, FFN | Matrix widths compatible | group128 along input row | Ordinary quantized linear paths are not automatically our custom binary codec |
| Conv in/out | Compatible by shape | same matrix codec | Must handle fused or split gate names and cache |

## 2. The transfer contract and mathematical audit

### 2A. A frozen codec contract, including short rows

The claim must be reproducible by a third party from a signed recipe manifest and the parent checkpoint alone. Distinguish literal shape-only transfer (no data-derived changes except already specified computation) from a **frozen model-conditioned procedure** (may measure weights or teacher activations with a fixed algorithm). The latter is meaningful scientific portability but should not be advertised as identical numerical hyperparameters if it re-derives them from measurements. If a future Qwen recipe uses calibration, transfer can only be claimed under the same calibration algorithm, not a stricter claim it never met. The project must freeze these semantics now, before reading target quality.

Proposed codec layout rule T1, to approve before Qwen training:

1. Each unique learned dense matrix is [out,in] in canonical mathematical order. Pack adjacent groups of 128 in the input dimension, never cross an ordinary matrix row. Tied E counted once, exact same reconstruction for lookup and multiplication. No independent scale head. One FP16 nonnegative finite magnitude per group, 128 signs. Define positive sign at latent zero and canonical scale-zero representation. Reject NaN, infinities and negative scales; no use of unused bit patterns as side channel. FP16 round-to-nearest-even fixed. Sign bit order, endianness and row/offset specification frozen, no model-dependent bit order.
2. For a depthwise kernel with one spatial input channel per output channel, serialize as a tap-major logical matrix [tap,channel]. A row is all channel coefficients for one tap. Groups remain consecutive 128 in channel order. This is an exact indexing transformation of the original tensor, no inference basis rotation. It is an explicit extension to the original definition of row. Inverse map is deterministic from tensor kind and shape; no learned side tensors. LFM2/LFM3 channel dimension 2048 gives 16 groups per tap. One conv layer costs 3×16×18=864 bytes or 7×16×18=2016 bytes respectively. Native storage [channel,1,tap] is restored as required by the graph.
3. Each learned vector of length divisible by 128 is treated as one logical row. For vectors with short residuals, use a deterministic per-block vector pool: concatenate only incomplete tails in canonical semantic order and make groups of 128. This gives the LFM2 pair of 64 Q/K gains a shared scale at each attention layer. Full vectors are not pooled across blocks. If tails do not divide 128, reject strict T1 until a padding policy is frozen (none in the named targets under this rule). Pairing Q/K is an explicit coupling, not an inference equivalence. An alternative T1-pad track packs each 64 into its own 128 slots with 64 fixed padding signs, cost 18 bytes per 64 learned values = 2.25 bpw locally, rather than a fake 1.125. If only 64 signs + one scale stored, it is 1.25 bpw and a different short-group format. Never label these alternatives as equal physical cost.
4. New scalar/bias tensor kinds not present in the targets trigger a preregistered reject or deterministic pool, not an exception invented after failure. Nonlearned constants (RoPE, shape metadata, fixed unit gain if provably folded) are reported in auxiliary bytes. Every originally learned coordinate either stored in a counted binary group or accounted for by an exactly proven reparameterization. Preserve architecture, no extra learned parameters, no side-trained codebooks, no runtime rotations. Report strict raw bytes, actual file bytes, and all nonlearned metadata independently.
5. The dense-matrix-plus-FP16-gain track is separate; kernel exception another separately named diagnostic if used. A dense-only Qwen winner cannot establish strict transfer. Before calling released Bonsai a strict anchor, inspect its gains and shared head. The previous decision report identified the exception ambiguity; do not retroactively treat the old 70.2% as a verified all-gain-binary score.

T1 is my proposed decision, not an already approved change. If literal row means original physical last dimension, it must be called an alternative format; the owner must resolve that before any strict LFM experiment. A deterministic layout convention applies to Qwen trivially (no taps, all gains divisible); it is not a target-optimized grouping. Optional channel sorting in idea e is a separate proposed procedure that must be specified and frozen before Qwen training, even though it is inactive on Qwen. That creates an untested branch of the recipe; report this limitation. Engineering validation on LFM2-350M must not tune the confirmatory target algorithm. It may repair a codec implementation defect under versioned tests, but parameter changes restart the preregistration.

```

```

### 2C. Idea a: fixed group norm with a closing cap

Verdict: exact feasibility theorem for a defined group, not a convergence theorem. Applicable to matrices, pooled gains and tap-major kernel groups under T1. Not applicable to an undefined three-tap row with a claimed 128 group.

Let m=128, R>=0, vector w constrained by ||w||_2=R and |w_i|<=c. Summing w_i²<=c² yields R²<=m c². Therefore c must be >=R/sqrt(m). At equality, sum_i(c²-w_i²)=0 and every term nonnegative, so every |w_i|=c. If R>0, signs specify exact binary vector at that boundary. If R=0, w=0 and signs irrelevant; canonical zero rule. If c<R/sqrt(m), no feasible vector. No optimization proof is required to establish this geometry. But it does not imply descent finds a good sign vector, nor that a schedule moves smoothly across signs at the boundary.

The exact projection of an update v onto this sphere-box intersection minimizes ||w-v||²=R²+||v||²-2 v^T w. Thus choose sign(w_i)=sign(v_i) for nonzero v_i and solve maximize sum |v_i|a_i over a_i in [0,c] with sum a_i²=R². For nonzero support and feasible radius below its capacity, Lagrangian yields a_i=min(c,t|v_i|), t>=0 chosen by monotone scalar root of sum min(c,t|v_i|)²=R². This is a global maximizer: it maximizes sum |v_i|a_i - lambda sum a_i² on the box for lambda=1/(2t); on feasible set the penalty is constant. If nonzero support cannot supply R², saturate those entries and distribute remaining norm among zero v_i by deterministic tie-break. At the endpoint t tends to infinity for unsaturated nonzero coordinates; directly set cap. Ordinary clip followed by renormalization is not this projection: rescaling clipped coordinates upward can violate cap. Ordinary renorm followed by clipping can violate norm. Require residual tests for both invariants after each projection.

Nearest Euclidean binary vector for unconstrained scale: choose s_i=sign(w_i), a=mean|w|. Expanding error gives ||w||² - (sum |w|)²/m. Let r=R/sqrt(m). Fixed-R closure instead gives m(r²+r²-2 r a)=2m r(r-a), versus m(r²-a²) for unconstrained mean magnitude. Difference m(r-a)²>=0. The closing rule forces RMS, not the optimal mean-absolute scale, unless magnitudes already equal. This is a potential extra approximation cost. During training the norm may move only if the schedule explicitly allows it before locking. An FP16 scale may not represent r exactly. Round r to a positive finite half c*, set final R*=sqrt(m)c* and report radius adjustment (or choose representable terminal cap first); exact norm fixed to arbitrary R and exact FP16 terminal scale are generally incompatible. The residual rounding error for fixed signs is m(c*-r)². Train with the actual half-represented forward scale before terminal export. No proof that this minimizes distillation loss. Tie gradients are summed before updates.

Weight-only test: compute initial max/mean/RMS per group, feasibility gap, RMS-vs-mean error, half-rounding residual, count zero groups and support degeneracy; unit-test projection on synthetic vectors, not a model. Compare each class. A small kernel group may have one shared scale across 128 unrelated channels; geometry is unchanged, error semantics are not. Do not infer task quality from small error.

### 2D. Idea b: exact diagonal gauge for double-gated shortconv

Verdict: valid after correcting the linearity premise; richer than a simple three-linear-map factorization. The sigmoid head gate is an important exception.

Write B,C,X as three independent d×d row blocks of I. For each channel j let nonzero real factors b_j,c_j,x_j,k_j,o_j obey b_j c_j x_j k_j o_j=1. Define diagonal matrices D_b etc. Replace:

```
B' = D_b B; C' = D_c C; X' = D_x X
K'_(tau) = D_k K_(tau)       (per-channel taps)
O' = O D_o
```

Then for channel j and token t, B'_t X'_t = b_j x_j (B_t X_t). Causal convolution of that channel multiplies by k_j as well. Multiplying C'_t adds c_j. O' multiplies column j by o_j. Product is one, so each channel's contribution to every output coordinate and time is identical. No assumption that B,C,X outputs are linear in their product; no mixing of channels is permitted inside the product. The full residual and any post RMS see exactly the original operator output. Finite precision can introduce small differences, so 'exact' means real arithmetic, verify rounding tolerances separately. Zero factors prohibited. Biases if present would need consistent transformation; selected config has no bias. Decode cache entries for B⊙X must be scaled/reordered consistently; initializing a cache from the old representation and then switching would break equivalence. Static model conversion at sequence start needs no such transition.

For any permutation matrix P, B'=PB, C'=PC, X'=PX, K'_tau=P K_tau, O'=O P^T. Elementwise multiplication is equivariant under permutation, and summation commutes with P. This is exact and useful for aligning groups. Signs are included in diagonal factors. Arbitrary dense rotations generally fail: (Ru)⊙(Rv) is not R(u⊙v). Counterexample R a 45-degree rotation, u=(1,0), v=(0,1), original product zero while rotated product has nonzero coordinates. No free rotation here. Similarly sigmoid(a z) cannot equal a sigmoid(z) for every z unless trivial cases; sigmoid(-z)=1-sigmoid(z), requiring an additional complementary branch to exploit it. The LFM3 attention gate cannot be rescaled like a convolution gate with no new parameters. Head permutations are possible only if Q/K/V/GQA mapping, gate rows, RoPE convention and O columns follow consistently. Global/sliding layer identities cannot be swapped across layers by this local proof.

The free O-column factor is genuine before quantization. But after binary conversion a nonconstant O column scale would break the common magnitude within a 128-input group; it must be used as a preconditioning variable then projected back. An exact gauge is not an exact mapping from any FP weight to a binary solution. Optimize e.g. a fixed weighted reconstruction objective over b,c,x,k,o with bounded log magnitudes and a product constraint; no retained gauge tensors at runtime. Weight-only compare per-group mean-error, balancing, condition numbers and half range before/after. A weight-only objective may reduce O error while increasing B/C/X or taps; count all tensors and avoid moving error unmeasured. If the objective uses activation covariance, that is a separate later authorized calibration, not a weight-only test.

### 2E. Idea c: post-normalization gains with frozen signs

Verdict: scale-only joint optimization is well-defined, but FP16 independent gain fitting is not the strict track. In strict mode gains themselves are groups of signed weights, not arbitrarily trainable independent scalars.

For N_g(z)=g⊙z/r(z), r=sqrt(mean z²+eps), if g_j=s_group sigma_j, then derivative wrt its group scale is sum over j in group of sigma_j (z_j/r) (dL/dN_j), summed over token positions and all uses. For a binary matrix W_{ij}=s_{i,g} sigma_{ij}, dL/ds=sum_j sigma_{ij} dL/dW_{ij}. For tied E the gradient dL/dE is the sum of embedding gather and head multiplication gradients. For an E row r, the lookup path accumulates dL/dh for every occurrence of token r; the head path accumulates dL/dlogit_r times the final normalized hidden vector over every token. Both contribute to the same scalar scale. Separate gradients do not authorize two scales. LFM2's pooled Q/K group sums gradients for both vector halves.

With scale-only fitting, latent signs remain unchanged. Stored scale must change to a different representable FP16 value to change the decoded model; FP32 optimizer state may accumulate tiny steps until a half boundary is crossed. Initial state reproduces a released strict checkpoint exactly if decode and positivity convention match; from full precision a group mean-absolute projection is generally not exact. A post norm is especially relevant: scaling its input uniformly changes normalized magnitude only by epsilon-dependent factor, so moving O globally may have a weak gradient. A post gain directly controls residual amplitude; groupwise changes can influence the residual balance. Do not assume post gain repairs all errors from a damaged sigmoid or a tap pattern. Test weight-only half quantization, gain distribution, sign balance, deviation from one, and compare scale sensitivity only after authorization to evaluate. Use separate arms S_matrix, S_gain, S_both (with gains quantized in all strict arms, frozen when not trained), and a separately labeled FP16-gain control. These isolate trainable degrees of freedom without conflating storage changes.

### 2F. Idea d: adapted FP32 versus original LFM2.5 weights

Verdict: strong natural paired control for adaptation geometry, not a randomized causal estimate of binary robustness. Use the exact same codec on both. Obtain header and SHA first, verify tensor sets and shapes and tie. Decode FP32 adapted and original BF16 values into common analysis dtype; do not confuse BF16 rounding with adaptation. For each group w define a=mean |w|, a_h=half(a), q=a_h sign(w). Then

```
||w-q||² = ||w||² - (sum|w|)²/m + m(a_h-a)².
```

Derivation: expand sum (|w_i|-a_h)²; add/subtract ma². Relative squared error divide by ||w||² (report zero-energy group separately). Compare weighted per-tensor error (sum error divided by sum energy), median/quantiles of group errors, sign Hamming fraction, log-scale changes, fraction at representable half boundaries, max/mean and RMS/mean, and tap shape error after per-channel normalization. Report gain groups, tied vocabulary rows (by frequency if an external frozen corpus provides counts), Q/K and other matrix classes separately. Also compute Q4_0 grid residual with the exact published quantizer, so that expected four-bit adaptation geometry is not confused with one-bit geometry. Permutation/gauge alignment may reduce apparent Hamming distance but must be fixed independently of target quality. Primary raw comparison plus separately defined aligned comparison. Adapted file uses FP32, original config BF16; include BF16-roundtrip adaptation control to measure dtype contribution. No model forward pass needed. If adapted weights have lower binary residual, it supports a geometric relationship only, not better token or task retention. If higher, it does not imply training failure, because four-bit objective is different. A matched data/optimizer randomization would be needed to isolate QAD as cause rather than correlated history. Do not replace original LFM2 with this control in the confirmatory test.

### 2G. Idea e: binary depthwise kernels and channel packing

Verdict: the proposed gauge and permutation are mathematically valid; the equal-magnitude approximation remains a substantive obstacle. Tap-major packing T1 works. A data-dependent permutation is permitted only as a preregistered weight-only algorithm with no runtime mapping beyond canonical stored channel order.

Let k_j in R^K, r_j=||k_j||_2 (or fixed chosen norm). If r_j>0, define k'_j=k_j/r_j, O'[:,j]=r_j O[:,j]. This is the b gauge with k=1/r and o=r. Zero filter: cannot divide by zero; choose factor1, mark degeneracy. Because each channel has different tap ratios, one scalar per channel cannot equalize arbitrary taps. Under tap-major grouping each group of 128 channels in each tap has one magnitude. After permutation, channel j has binary coefficients q_{j,t}=a_{g(j),t} sigma_{j,t}; all 128 channels in group g share the same absolute tap-vector pattern (a_{g,1},...,a_{g,K}). Relative signs can differ, and O columns can rescale overall response, but normalized absolute shapes cannot differ within the group. For K=3 there are at most 8 sign patterns per fixed magnitude pattern; for K=7 at most 128. This is an intrinsic constraint, not merely a packer limitation. Tying every tap to one scale per channel would be a different short-group codec.

For fixed normalized taps and group membership, optimal squared-error a_{g,t} is the mean absolute tap in group, and total error sum_{g,t} sum_{j in g} (|k'_jt|-a_gt)^2. Sorting/grouping by normalized **absolute** tap vectors (not signs alone) directly reduces this objective; the per-channel signs remain free. A concrete deterministic weight-only proposal: sort lexicographically by largest-absolute-tap index, then by normalized absolute taps in canonical order, stable tie by original channel index; group consecutive 128; apply P consistently to B,C,X,O and K. Compare to unsorted T1 and gauge-only. A more ambitious balanced clustering objective is capacitated clustering with exactly 128 channels per cluster; solve using fixed algorithm/seeds and compare sum of within-cluster variances, not quality. A useful alternative gauge chooses scale r_j to trade filter residual against O column residual simultaneously, fixed constraint on dynamic range. Because the projection matrices are huge, a kernel-only objective can worsen overall conversion even if kernel error improves. Do not infer net benefit from lower filter error.

Weight-only test: original versus normalized channel shapes, sign entropy, per-group covariance of tap magnitudes, normalized transfer function at fixed frequency grid, and L2/Frobenius error after exact gauge+permutation and projection. FIR frequency response H_j(omega)=sum_t k_jt exp(-i omega t). Parseval for equally spaced grid covering at least K frequencies gives mean |H-Hq|² = sum_t |k_t-kq_t|²; cancellation at specific frequencies can be damaged even when mean error small. These are filter-level tests, not LLM inference. The LFM block gates modulate input and output, so treating filter spectrum as a language model sensitivity estimate would be unjustified. Width7 gives more shape degrees than width3, not a proven monotonic loss difference. Permutation acts on physical weights offline and keeps tensor shapes; no index vector stored if the entire block is consistently rewritten.

### 2I. Idea g: folding normalization gains before conversion

Verdict: exact for direct linear consumers only, with important exceptions in these architectures. Not a universal way to remove learned gains without changing the function. Proofs below assume real arithmetic and nonzero factors where inverses are required.

Let N_g(h)=D_g n(h), where n is unit-gain RMS. If every consumer is a linear projection W_i, W'_i=W_i D_g and g'=1 preserve W_i N_g(h)=W'_i n(h). For pre-operator norm this includes all Q/K/V projections and LFM3 attention gate projection, or the three conv input projections. For FFN pre-norm includes both gate and up, not down (down sees their product). This works despite downstream SiLU or sigmoid because the actual arguments are unchanged. If bias present keep original bias. If D_g contains zero, multiplication still works for direct consumers; invertibility is not required. Such folding changes group magnitudes and may worsen binary projection. Weight-only compare before/after for all affected matrices and gains. Frozen unit gains need no learned values; if stored by runtime, account actual bytes. If strict score denominator counts original learnable coordinates, report both original count and post-fold count so removal cannot inflate storage compression claims. Keeping unit binary gain groups is an alternative with exact original parameter count and very small payload.

Post-sublayer norm in LFM3 is followed by residual addition. It has no sole linear consumer. Trying to absorb D_g into preceding O produces N_1(D_g z)=D_g z / sqrt(mean g² z²+eps), whereas N_g(z)=D_g z / sqrt(mean z²+eps). Equal for every z only if |g_j|=1 for each j (or trivial restricted outputs); arbitrary learned magnitudes fail. A common scalar a gives denominator sqrt(a² mean z²+eps), not simply a times old norm. Even ignoring eps, output scaling cancels in RMS normalization, so it does not reproduce an arbitrary scalar gain. Global residual reparameterization by signed permutation can commute with RMS, but a diagonal nonuniform change cannot preserve it generically. Counterexample z along two coordinates with different g; denominator ratio depends on z. Cannot move post gains into next layer's matrices because the residual path bypasses those matrices and next normalization is nonlinear. Therefore post norms are new strict binary targets that cannot generally be folded away.

Final norm + tied vocabulary E: logits E D_g n(h). Folding E'=E D_g would preserve logits for given h but changes lookup from E^T onehot to D_g E^T onehot, so hidden states change. Keeping input E and output E' unties the matrix, forbidden. A coordinated residual basis P signed permutation preserves inner products and normalization with consistent gain permutation; general learned diagonal D does not. If g entries differ, even arbitrary orthogonal residual rotation does not commute with diagonal gain; for generic distinct gains, only signed permutations preserve diagonal structure (within equal-value eigenspaces more freedom). This is a constraint, not a claim no exact special transformations exist for a particular trained E. Q/K RMS gains are followed by RoPE and dot product, not sole linear consumers. They cannot generally be folded backward into Q/K weight rows because their denominators depend on all coordinates. A reciprocal diagonal pair A and A^{-1} applied after Q/K normalization preserves dot product if it commutes with both position rotations and respects GQA/head-sharing. For rotated coordinate pairs A must have equal scalars per paired plane (unless particular degenerate rotations); on unrotated coordinates reciprocal factors free. This moves gain between Q and K but does not remove both unless product is suitable. LFM3 has partial rotary global and full rotary sliding; apply by layer type, not global assumption. A sign inversion of a full head's value and its corresponding O columns is exact; gate remains unchanged. More generally, within a KV-head value subspace an invertible transform T can be applied to V and inverse to O columns for every query head using that KV head, since attention weights are scalars and the scalar sigmoid gate commutes. That is a pre-quantization gauge, not free additional stored transform.

SwiGLU exact freedom: scale up projection rows by nonzero a_j and down columns by inverse; permutation of gate/up rows and down columns is exact. Scaling gate rows before SiLU generally not homogeneous (SiLU(a x) differs from a SiLU(x)), so no equivalent arbitrary gate scale. This and convolution gauge are useful because they can change group error with no runtime transform. A proof for a single layer does not automatically extend across residual streams; verify all fan-outs, nonlinearities, norms, ties and cache. No graph with generic arbitrary matrix rotation is accepted by this proof. Any proposed fold must specify every consuming edge and whether it preserves target graph and parameter tie. Test algebra on tiny synthetic arrays without instantiating LLMs, then validate exact graph later under approved testing.

### 2J. What constitutes a transfer success

Use the project's own accepted ruler, not any publisher's numerical result as denominator. For task t let score S_{m,t} be percent points on pinned scorer, averaged in prescribed hierarchy. For parent P and strict student B of model family m,

```
A(P_m) = sum_t S(P_m,t)/10
A(B_m) = sum_t S(B_m,t)/10
R_m = 100 * A(B_m)/A(P_m)
D_m = R_m - R_Qwen
```

The sum ratio is not the mean of taskwise ratios. At reference 58.24, five points of retention requires 29.12 summed task-score points; LFM's denominator will differ. Use the independently converted Qwen strict model as primary reference, not Bonsai refinement or Boole's outside harness. Multiple Qwen training seeds estimate a procedure, not only the selected best seed. Report best artifact separately. No LFM target has been evaluated under the accepted ruler. If Qwen fails to attain useful quality, equal bad retention is not a meaningful transfer success. I propose preregistered Qwen usefulness gate R>=70% on internal ruler (and report actual released-anchor score separately); require target also at least 65% if using a five-point equivalence margin. These are proposed thresholds, not historical scores or owner decisions. If the eventual intended target is 90% or higher, report the specific Qwen level at which transfer was tested. Equivalence at 72% cannot imply equivalence at 99%.

Primary equivalence decision: two one-sided tests with margin ±5 retention points (not percent relative), alpha=.05, or equivalent 90% confidence interval for D wholly inside (-5,+5). A point estimate inside the band but interval crossing a boundary is inconclusive, not success. Separately report noninferiority if the lower one-sided 95% bound is >-5; superiority >+5 can fail two-sided equivalence while being an engineering success. Do not call it a failed conversion in that case. Use at least five independent training seeds for each family, shared predeclared seed identifiers/data-order policy but not pretending optimization trajectories are paired identical noise. Add seeds according to a preregistered variance/power rule independent of observed treatment effect, no optional stopping on favorable test means. Evaluation stochastic repeats are nested within checkpoint and task, not substitute independent training seeds. Use same raw question IDs across parent/student and model families, paired scorer outcomes and paired bootstrap of examples or clusters. For prompts with multiple constraints or repeated choice permutations, cluster at original prompt/question. BFCL subsets are strata with official aggregation weights. For coding, unit tests within a problem are not separate benchmark items. Use nested bootstrap or hierarchical model of training-seed and evaluation-item effects; report both. Parent evaluation variability included, denominator and numerator resampled jointly; no independent ratio error approximation if paired data available.

Derivation of a simple paired binary-task SE: per item d_i=B_i-P_i in {-1,0,1}, sample variance = [sum d_i² - n dbar²]/(n-1), SE(dbar)=sqrt(var/n). With binary outcome fractions p10, p01, E d²=p10+p01, variance=p10+p01-(p10-p01)². Disagreement, not marginal item count alone, decides precision. For a weighted task macro mean, variance of sum w_j dbar_j includes cross-task covariance if items overlap or seeds correlated. For ratio R=100 A_B/A_P, first-order gradient (100/A_P,-100 A_B/A_P²); Var(R) approx g^T Sigma g. For D, include covariance of R_LFM and R_Qwen from shared task difficulty/seed structure. Joint bootstrap more robust to nonlinear scorer and denominators. A lower bound on sample-size planning with approximately normal difference variance sigma² per independent unit, true difference zero, margin m=5: to get 80% equivalence power, approximate SE <= m/(z_.95+z_.90) = 5/(1.645+1.282)=1.71 points (symmetric interval power, known variance). Use t or simulation for small seed counts; fixed five is a minimum not guaranteed sufficient. If per-seed standard deviation 4 points and independent families with equal n, SE=sqrt(2)*4/sqrt(n), need ~11 seeds per family even ignoring item uncertainty. If item-level uncertainty dominates, more training seeds cannot solve it. Report fixed-suite exact scores and sampling interpretation separately. For two confirmatory LFM targets, preregister familywise error control if claiming both as one result, e.g. Holm for separate equivalence tests; otherwise report separately locked claims. Do not silently count a separate LFM2.5 control as third confirmation.

Near-chance tasks: retain all ten in the product metric. Publish P_t, B_t, paired delta, a fixed chance or no-skill baseline C_t when well-defined. Secondary chance-adjusted aggregate `100*sum(B_t-C_t)/sum(P_t-C_t)` only on a preregistered set with defensible chance models and sufficiently positive denominator; not on open-ended tasks with arbitrary chance. Per-task chance-adjusted ratio undefined or unstable when parent near C_t. In that case report absolute difference and uncertainty and explicitly flag that raw retention mostly measures chance preservation. Do not drop tasks after observing parent scores. Absolute task guardrails from accepted decision policy applied identically; a high aggregate can conceal severe tool or code degradation. Require disclosure of every regression even if an overall step passes. The primary equivalence test would wrongly pass two equally weak models, common harness bugs, or complementary task collapses with same aggregate; usefulness gate, per-task profiles and ruler audit mitigate but do not eliminate. It would wrongly fail a genuinely equivalent method with insufficient sample precision, a model whose native template is unfairly constrained, or a target much better than Qwen; classify uncertainty, mode confound and superiority separately. It cannot prove generalization to all LFM variants or all tasks.

### 2K. Failure attribution: what can and cannot be isolated

A comparison between Qwen and LFM is not a randomized architecture experiment. Architecture, tokenizer, parent data, training history, quality, number of parameters, and quantization geometry all differ. No small collection of post hoc rescue arms can uniquely assign the shortfall to one cause without assumptions. In particular the question 'smallest set that would put it down to one cause' is overstrong. Interactions can make two individually harmless quantized parts fail together. The following is a minimal diagnostic ladder for prespecified hypotheses, not proof of unique decomposition.

| Arm | Change relative to frozen strict target | What it diagnoses | Claim cost |
|---|---|---|---|
| F0 | exact strict frozen conversion, no changes | primary transfer outcome | none |
| F1 | identical training, FP16 kernels only | conditional kernel rescue | no strict compliance; diagnostic |
| F2 | identical training, FP16 gains only | conditional gain rescue | dense-matrix track, not strict |
| F3 | both kernels and gains FP16 | interaction F3-F1-F2+F0 | diagnostic outside strict |
| F4 | for LFM3 only, protect sigmoid gate matrix (binary other matrices) | distinct attention gate mechanism | outside strict, no confirmatory claim |
| F5 | tie retained, shared E FP16 while body binary | vocabulary contribution | outside strict |
| F6 | same shape/codec on original LFM2.5 checkpoint (own FP teacher) | history-sensitive response at nearly same graph | separate control, not causal isolation |
| F7 | same LFM2.5 shape, compare original vs adapted FP32 source, binary both | Q4-adapted geometry/history sensitivity | separate parent and teacher track |
| F8 | change data exposure law alone or predeclared corpus arm | sensitivity to tokenization/content | new recipe branch, unless law was fixed on Qwen |
| F9 | one fixed change to optimization schedule or loss | settings interaction | retuned, not frozen transfer |

All repairs can be crossed with frozen sign/scale training masks to distinguish representation rescue from retraining adaptation. A zero-shot checkpoint where one group is restored to FP16 tests immediate functional perturbation around a given model, not retraining benefit; no inference run now. Pair each rescue with appropriate randomized same-size control if asking whether new tensor kinds are unusually sensitive, not merely whether relaxing any constraint helps. If F1/F2 rescue is large despite tiny byte share, that is valuable scientific information, not permission to promote to strict. A strict alternative (tap-major permutation, gain folding, post-gain scale optimization) must be labeled as new recipe if it was not predeclared. Interactions F3-F1-F2+F0 quantify departure from additivity conditional on the trained models; causal effects include changes in all parameters during retraining. To isolate architecture vs training history would require matched counterfactual families trained with same data/teacher/objective across graphs, or matched trajectories within architecture. LFM2.5 original/QAD is closer than LFM3 vs Qwen but still not randomized. No claim that one causal explanation is identified by failure alone. The cheapest no-model tests are header/codec validation, weight-only geometry, algebraic gauge and deterministic serialization tests; those can rule out implementation mismatches before expensive or small experiments equally. Time/compute are not grounds to exclude any causal arm.

### 3A. Mirror descent and implicit bias

[1906.03830](https://arxiv.org/html/1906.03830) and [2202.10788](https://arxiv.org/html/2202.10788): partial HTML and earlier navigation. The key issue is whether interpolation, local initialization and convex-potential hypotheses actually cover a nonconvex decoder. Classical SMD state is dual xi=grad psi(w), xi_next=xi-eta grad loss(w), w_next=grad psi*(xi_next). A Bregman projection theorem onto an affine interpolant set does not establish that this set intersects a binary group constraint. For nonlinear network, global affine feasibility is lost. I did not independently read all local-neighborhood, step-size and explicit-regularization proofs. No convergence claim for 1.7B follows. [2510.16250](https://arxiv.org/html/2510.16250), inspected theorem/assumption passage: random-feature Gaussian equivalence assumes d/n approaches kappa>1, strong convexity, smooth third derivatives and a controlled solution gradient, with linear interpolation constraints Xw=y. Its equivalence is for Lipschitz functions of minimizers, e.g. quadratic prediction errors asymptotically. A nonsmooth rigid cage may violate its smoothness conditions; tied matrices, multiplicative gates and compositional autoregressive decoding are not the linear random-feature model. [2602.18997](https://arxiv.org/html/2602.18997) theorem 1: unique Bregman minimizer subject to a linear operator A(W)=b under listed assumptions. Additional assumptions yield expected squared error bounded by a geometric factor `(1-eta*mu*sigma_p(A)^2/(2pL))^t` times a Bregman-distance constant. A matrix-valued variable is not by itself a nonlinear network theorem. [2402.10474](https://arxiv.org/html/2402.10474) and [2311.02270](https://arxiv.org/html/2311.02270): partial setup and appendix navigation, regularized regression for multiclass/binary classification, Gaussian mixture/CGMT conditions; not proofs for network-level group128 exact binary endpoints. No complete numerical extraction from either.

[1910.08237](https://arxiv.org/html/1910.08237), inspected theorem 2 and appendix theorem 3: convex Lipschitz objective on a compact convex set, strongly convex mirror map, annealing bounded 1<=beta<=B, average iterate error O(1/sqrt(t)), explicit bound RL sqrt(2B/(rho t)). A bounded sharpening guarantee is not a proof that beta→infinity or an individual terminal iterate reaches ±1. At finite beta, tanh(beta xi) generally remains interior. At xi=0 it is zero for any beta. Need terminal exact projection and measure residual; a hard endpoint with no crossing can stall. The [md-bnn README raw](https://raw.githubusercontent.com/kartikgupta-at-anu/md-bnn/master/README.md) is accessible, notes older framework and exact reproducibility caveats; the actual optimization source not fully audited.
```
w = argmin_w [eps/2 ||w||² + ||w||inf - xi^T w]
  = argmin_w [eps/2 ||w-xi/eps||² + ||w||inf].
```

Introduce cap r>=0, |w_i|<=r; for fixed r the solution is w_i=sign(xi_i) min(|xi_i|/eps,r). The derivative wrt r of the optimized objective is `1 - sum_i max(|xi_i|-eps*r,0)` for r>0. If ||xi||1<=1, derivative at r=0 nonnegative, optimum all zero. Otherwise solve sum_i max(|xi_i|-alpha,0)=1, alpha=eps*r. For active top k, alpha=(sum_{i<=k}|xi_i|-1)/k, satisfying |xi_k|>=alpha>=|xi_(k+1)|. Correct unsaturated branch xi_i/eps. This is unique from strong convexity, even though the subgradient at a cap tie is set-valued. Complete equal magnitudes require all entries active and nonzero or zero cap. A small eps amplifies magnitude but does not alone make all entries active: the threshold alpha is determined by xi, not eps. For example xi=(3,.1), eps=.2 gives alpha=2 (only first active), w=(10,.5), not equal magnitudes. A valid dual update stores xi to avoid ambiguities from reconstructing a subgradient at tied maxima. This explains precisely why the patent's proposal, even if implemented correctly, does not prove a binary endpoint. It is also distinct from fixed-R sphere-box closure in 2C, which enforces endpoint by geometry, at the cost of nonconvex projection. Need no patent numerical claims to make these deductions. Read the actual drawings and WO publication to check notation and examples. No evidence in this audit of a proven exact g128 nonlinear-decoder convergence guarantee.

### 3C1. Full primary PDF audit: Noda, cross-layer error compensation

**Read in full from the primary file:** [arXiv 2607.14630v1 PDF](https://arxiv.org/pdf/2607.14630), pages 1-10, all three tables, appendices A-C and references. There are no plotted figures in these ten pages. The implementation notebooks are described on page 8 as available from the author; no public notebook link is provided there and I have not obtained them. Thus the paper is fully read, but the implementation is not verified. This is not a source-code replication.

The authors' exact finite-difference identity (Lemma 1, page 4) is correct. Let F_l be the teacher layer, G_l the quantized layer, h_l the teacher input, e_l the difference of student and teacher inputs, q_l=G_l(h_l)-F_l(h_l), and Ahat_l(e)=G_l(h_l+e)-G_l(h_l). Then

```
e_(l+1) = G_l(h_l+e_l)-F_l(h_l)
        = [G_l(h_l+e_l)-G_l(h_l)] + [G_l(h_l)-F_l(h_l)]
        = Ahat_l(e_l)+q_l.
```

Induction from e_0=0 proves the recursion for arbitrary layer maps. The final loss is a teacher-normalized final-feature squared difference. This requires no special linearity of LFM and no explicit Jacobian, but is algebraically ordinary joint final-feature matching. It does not prove local sequential compensation converges to the same solution, nor that the proposed objective has a better global minimizer than logit KL. For a tied embedding converted too, e_0 is generally nonzero if the recursion begins after embedding; either include the embedding as layer zero with identical token input, or set e_0 to its actual error. The identity still holds. An output projection can likewise be included in the composition, with the same reconstructed E in both roles. This extension is exact algebra, not an experiment.

Three important corrections to the mathematical wording of this paper:

1. **Initialization is not exact teacher reproduction.** Equation (8), page 5, initializes s0=mean(abs(W)), z0=atanh(clip(W/s0,-rho,+rho))/beta0 with rho=.95. Substituting gives W_hat0=s0*clip(W/s0,-rho,+rho), not W. For any nonzero group, max(abs(W)) >= s0 > .95*s0; at least one coordinate is clipped. Even a group already at one common magnitude becomes .95 times its original value. Appendix A correctly shows the *signs* reproduce RTN; the unit test on page 7 explicitly checks clipped, not original, magnitudes. The initialization claim on pages 2 and 5 is stronger than the equations support. Exact soft reconstruction requires s0 > max(abs(W))/rho and correct inverse mapping, or a different map. The resulting scale is then not the least-squares binary scale. Test initialization separately from hard-forward endpoint.
2. **The inverse mirror map is correct, but the specified gradient step is not ordinary mirror descent on the primal objective.** Appendix A defines psi_beta(u) as scaled binary entropy, z=atanh(u)/beta, u=tanh(beta*z). For a differentiable objective J(u), exact mirror descent at fixed beta gives z_next=z-eta*grad_u J, u_next=tanh(beta*z_next). Euclidean gradient descent through the parameterization instead gives grad_z J=beta*(1-u^2)*grad_u J, elementwise, hence z_next=z-eta*beta*(1-u^2)*grad_u J. These are unequal unless special values of u or a compensating preconditioner apply. AdamW on z changes the update further. The paper's appendix explicitly uses partial J/partial z and its experiment specifies AdamW; therefore the claim of exact mirror-descent dynamics does not follow. Annealing beta changes the potential between steps, which requires another convergence analysis. This is especially consequential near saturation, where the chain-rule factor vanishes. The paper's hard-forward final 20% is a separate operation and does guarantee hard codes at export if the specified scale is positive and serialized correctly. It does not establish all latent magnitudes have converged to binary; the paper reports residual softness .028 and sign flip fraction approximately .0003 near termination.
3. **Finite sample statistic equality is not distribution equality.** The feature mean, projected covariance, and centered Gram matrix can coincide while underlying distributions differ. Even the empirical samples can be transformed in an unobserved subspace preserving Gram and projected covariance. Therefore zero discrepancy verifies those chosen statistics, not teacher identity or equality of full distributions. Page 7's stronger unit-test wording is not a mathematical iff for arbitrary distributions. The experimental finding that matching statistics alone catastrophically worsens perplexity is consistent with this limitation. Its own Appendix C warns of nonzero finite-rank CKA bias. The identity above concerns actual pointwise features, not merely statistics.

Training details from pages 5-7: Qwen2.5-1.5B, all 196 block linear matrices (about 1.31B values), embedding and LM head FP16, group128, calibration WikiText-2 train approximately 130k tokens, 1000 steps of batch8 by length512 (4.096M token positions), AdamW latent LR 5e-4 and log-scale LR 5e-3, beta 1 to16 exponentially, seeds 1234,2025,7. The INT4 arm uses 300 steps and lower LRs 2e-5/5e-4. Logit KL uses top256 teacher logits at temperature2. Thus the comparison with KL is not a claim about a full-vocabulary exact teacher objective. Table 1 PPL values are ratios, not absolute perplexity and not task-score retention. Multiplying the best ratio 9.56 by teacher 11.951 gives 114.25156. RTN and local reconstruction are much worse. Table 3 gives different WT2 ratios for the same labels than Table 1 (e.g. 9.62 vs9.56); the paper says the same checkpoints, but gives no explicit accounting of the discrepancy in the text I inspected. Do not merge these as duplicate measurements or use the quoted across-seed differences as a formal significance test without paired values. Table 2 supports the objective's applicability to another quantization alphabet, not unchanged transfer between model architectures. Page 7 notes the local baseline is their own proxy, not a tuned public GPTQ or QEP comparison, and no downstream task scores exist. The paper explicitly proposes fully binarized experiments as future work. Its nominal 1.125 bpw is only the quantized block matrices; the FP16 excluded tensors increase overall bpw.

### 3D1. Full PDF audit: random binary perceptron and an arithmetic discrepancy

**Read in full from the primary file:** [Altschuler and Tikhomirov, 2401.15092 PDF](https://arxiv.org/pdf/2401.15092), all four pages visually inspected including the proof and the MATLAB appendix. The proof invokes previously established spherical free-energy concentration/results rather than reproving them; those external works have not been fully audited here. The source is a bound for one Gaussian random-pattern perceptron, not a decoder capacity theorem.

The setting is A with t by N iid standard Gaussian entries, t approximately alpha*N, and Z(A)={x in {-1,+1}^N: Ax >=0 coordinatewise}. For fixed x, each of t independent signs of Ax is equally likely, so E|Z|=2^(N-t). Markov's inequality gives the crude alpha>1 upper bound. The authors improve this by using the spherical feasible-volume fraction, taking its log normalized by N with a lower truncation, and restricting the counting argument to typical spherical volume. Because Gaussian A is invariant under right orthogonal multiplication, randomizing by a Haar orthogonal matrix does not change the distribution or the invariant typical-volume event. Conditional on a fixed A, each binary vector is uniformly oriented on the sphere by the random rotation, so its probability of feasibility equals the spherical fraction. Union-bound over 2^N binary vectors. If on the typical event the spherical log fraction per dimension is strictly below -log(2), the resulting bound tends exponentially to zero; the atypical event probability tends to zero by the cited concentration. No independent feasibility assumption for different binary vectors is required.

The paper uses the cited Gardner-Derrida free energy evaluated at q=.5. The relevant expression simplifies because the Gaussian tail probability of a standard Gaussian is Uniform(0,1), so E[log H(U)]=-1 (with U standard Gaussian and H its upper tail). Then

```
GD(alpha,.5) = -alpha + .5*(1+log(.5))
GD(.847,.5)  = -.6935735902799727
-log(2)     = -.6931471805599453
slack       = .0004264097200274
```

**Arithmetic correction:** the PDF states this evaluation is below -log(2)-.002. It is not; the slack is only .0004264. The intermediate threshold using .001 is likewise not justified by that particular calculation. This does not invalidate the main .847 bound. Choosing a fixed smaller positive slack, for example .0001, yields the same asymptotic proof using concentration. In fact this q=.5 trial yields a strict inequality for alpha>(1+log(2))/2=.8465735902799727 under the cited free-energy formula, because -alpha + .5*(1-log(2)) < -log(2) rearranges to that threshold. The appendix numerically searches q=.001 to .999 in steps of .001, alpha near .846-.847, with Gaussian integrals truncated at ±10 and a machine-epsilon safeguard; its plotted reference .84655 can reflect optimizing q rather than the simple q=.5 evaluation. Do not confuse that numerical grid with a rigorously certified optimization error bound. The printed MATLAB listing appears to define the alpha vector as `a` but subsequently references `alpha`; literal execution would require resolving this identifier mismatch. Neither issue overturns the elementary sufficient inequality above. No later erratum was verified. I checked the scalar arithmetic independently, not by running the MATLAB code or sampling a model.

Applicability: the Gaussian rows are independent random constraints; a transformer has multiple learned matrices, structured nonrandom features, residuals, weight tying, nonlinearities, and 16-bit group scales. The number of constraints per perceptron is not bits of teacher knowledge per decoder parameter. The bound cannot be substituted into a prediction of 90% or 99% ten-task retention. It motivates considering a geometric capacity diagnostic in a deliberately defined random-pattern subproblem, not excluding a training route. The independent finite-state counting argument in 3D is the appropriate codec-level upper bound, and it too requires a specified source entropy and distortion metric before it limits a target.

### 5A. Practical header acquisition protocol

Use public HTTP Range requests on a *pinned* safetensors shard rather than downloading all weights. This sample is an unexecuted acquisition snippet; it is not a model loader. A compliant server returns an exact 206 response. If a CDN ignores ranges, do not interpret the first bytes of the full file as the requested later slice. Download the public file once to a disk with sufficient space or use its local file directly; no credential workaround. Validate the response Content-Range and header size. Record URL/revision, file length and hash of header bytes. Reconcile every shard from the index JSON; a single header is not an inventory of a sharded model.

```python
import hashlib, json, re, struct
import requests

def span(url, start, end):
    with requests.get(url, headers={"Range": f"bytes={start}-{end}",
                                    "Accept-Encoding": "identity"},
                      stream=True, timeout=90) as r:
        r.raise_for_status()
        m = re.fullmatch(r"bytes (\d+)-(\d+)/(\d+)",
                         r.headers.get("Content-Range", ""))
        if r.status_code != 206 or not m:
            raise RuntimeError("Range unsupported; inspect a local public copy")
        a,b,total = map(int, m.groups())
        if (a,b) != (start,end) or total <= b:
            raise RuntimeError("Unexpected Content-Range")
        data = r.raw.read(end-start+1)
        if len(data) != end-start+1:
            raise RuntimeError("Short response")
        return data,total

def header(url):
    first,total = span(url,0,7)
    n = struct.unpack("<Q",first)[0]
    if not 0 < n <= min(100_000_000,total-8):
        raise ValueError("Invalid header length")
    payload,total2 = span(url,8,7+n)
    if total != total2:
        raise ValueError("File changed during reading")
    h = json.loads(payload)
    for name,entry in h.items():
        if name == "__metadata__":
            continue
        a,b = entry["data_offsets"]
        if not 0 <= a <= b <= total-8-n:
            raise ValueError(f"Bad tensor offsets: {name}")
    return {"url":url,"size":total,"header_sha256":
            hashlib.sha256(first+payload).hexdigest(),"header":h}
```

For local safetensors, read first eight bytes, then exactly n bytes, then verify tensor data ranges against os.stat size. For GGUF, use the upstream `gguf` Python package's `GGUFReader` on a local public copy (memory mapping for metadata and byte ranges, no model inference) or a separately reviewed GGUF header parser supporting its metadata types and alignment; export tensor names, logical shapes, quantization enum, byte lengths, offsets, and file metadata. Distinguish an auxiliary nonlearned RoPE tensor from trained weight and account for duplicated embedding/head explicitly. Verify physical payload sum against file size minus alignment/metadata. Reading headers alone cannot establish sign agreement, magnitude structure or checkpoint equality; those require weight-only byte comparison. For the QAD pair, load matched raw tensor arrays one at a time, compare hash/equality, shape, type and group statistics, convert only arrays to a common arithmetic dtype, and avoid instantiating any inference graph. ## 6. Closing recommendations and new hypotheses

1. Resolve the logical-row definition now. The project can preserve exactly 1.125 raw bits per learned value under T1 for these targets, but only if the tap-major kernel layout and paired short Q/K gains are explicitly accepted. Without that decision a strict LFM claim is not well-defined. Report the native logical tensor shape, codec shape and inverse map separately. Do not use padding or precision exceptions without counting them.
2. Freeze the transfer contract before any Qwen recipe optimization that could choose grouping, calibration, loss, or gauges. A procedure with a new architecture-dependent branch is not automatically demonstrated by Qwen success; it can still be a useful preregistered transfer claim. Keep LFM2-350M engineering checks separate from algorithm selection and lock each confirmatory target independently.
3. Use the exact gauge as a hypothesis-generating tool. Try only function-preserving offline transformations whose inverse factor is compensated within the same block. A promising comparison is a deterministic minimization of the sum of group binary approximation errors across the coupled convolution factors, not merely optimizing the kernel in isolation. Relative factor scaling changes the group geometry of other projections, including projection-out columns. Restrict positive scaling ranges and tie-breaking by a fixed rule for numerical stability. Measure group sign/magnitude error before and after, with the same total bit count. This is a new optimization hypothesis, not proof that it preserves quantized accuracy.
4. Separate frozen-sign gain optimization from the strict sign/scale optimization. Under strict storage, gains grouped together cannot move independently. A dense-matrix-only gain training result is a separate track. Folding exact eligible gains into parent matrices can reduce one source of binary coupling but may worsen matrix magnitude distributions; include no-fold as an equally valid arm. LFM3 post-gain folding generally fails. The new distinction is specific and testable, not an architecture-based blanket preference.
5. The paired QAD geometry test should precede any claim that prior low-bit adaptation helps binary conversion. Compare per-group E2 and magnitude CV, plus the *distribution* of improvements by tensor kind, not just total average. A 4-bit adaptation could create multiple useful magnitudes rather than a binary shell. Keep original and adapted teachers distinct in later functional tests.
6. Treat Noda's final-feature objective as a separable loss hypothesis, with the exact embedding error term, rather than accepting a mislabeled optimizer. An explicit primal-gradient mirror update versus Euclidean latent AdamW with the same map and hard-forward schedule is a clean prospective ablation. Correct the initialization and record its actual teacher error before first update. No evidence here warrants replacing the current experimental sequence with this candidate before the required theory and specification checks.

This demonstrates why the remaining appendix and code audit matters; neither a long report nor successful algebra licenses certifying unread evidence.
